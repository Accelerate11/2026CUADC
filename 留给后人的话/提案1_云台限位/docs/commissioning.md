# 分阶段调试与飞行验证方案

任何一步出现方向不确定、机械碰限位、舵机发热、BEC 掉压或高频抖动，都先 `DISARM`/断开舵机电源，排除后再继续。首次闭环绝不能直接装到已解锁的无人机上。

## 阶段 A：只接 MCU 与 IMU

1. 不接舵机电源，编译并下载固件。
2. 打开 115200 串口。上电时保持 IMU 静止，依次应看到：
   - `INFO,CALIBRATION_KEEP_STILL`
   - 约 2 秒后 `INFO,READY`
3. 水平放置，检查 `accel_norm` 约为 1，Roll/Pitch 接近 0。把板绕 X、Y 轴各转 +20°，核对对应角度方向和数量级。
4. 若静止水平时不是 `AZ≈+1 g` 对应的姿态，修改 `app_config.h` 的轴符号；若轴互换，则在 IMU 驱动输出处做轴置换。
5. 静止记录 60 秒：角度不应持续单向漂移，IMU 失败计数应始终为 0。

建议保存数据并计算：角度均值、标准差、峰峰值、加速度模长范围和串口丢帧率。

## 阶段 B：只验证 PWM 和机械行程

1. 拆下舵臂，接示波器/逻辑分析仪：PA0、PA1 应为 50 Hz，READY 时约 1500 µs。
2. 核对配置的 1000/1500/2000 µs 没有超出舵机厂商范围。
3. 断电后装舵臂，使 1500 µs 对应机构机械中位。
4. 先临时把软件行程收紧到 ±10°，低电流限制上电。发送 `SET,5,0` 后 ARM，观察 Roll 轴的缓慢响应；DISARM 后做 Pitch。
5. 分别手动轻微扰动每个框架，确认控制动作是“抵抗扰动”。若动作放大扰动，立即断电，并翻转对应 `k*ServoDirection`，不要尝试靠调小增益解决正反馈。

## 阶段 C：单轴闭环整定

机械锁住另一个轴，每次只整定一个轴。

1. 从保守参数开始：`GAIN,R,2.0,0.4,60,60`。
2. 缓慢倾斜底座 ±10°：逐步增加 `attitude_kp`，直到恢复速度够用但没有明显过冲。
3. 增加 `rate_kp` 提高阻尼和扰动抑制；一旦出现高频啸叫/舵机来回抖动，退回 30%～50%。齿隙导致的极限环不能靠继续加增益消除。
4. 最后按舵机能力提高 `max_target_rate` 和 `max_servo_slew`。先保证稳定，再追求速度。
5. Pitch 轴重复相同步骤。

串口增益只在本次上电有效。确定参数后写回 `AxisGains` 默认值或增加 Flash 参数存储。

## 阶段 D：双轴台架试验

1. 将整个无人机或等效底座固定在可控的两轴台架上，螺旋桨必须拆除。
2. 做阶跃：底座分别从 0° 转到 ±5°、±10°、±20°，记录 10%～90% 上升时间、超调、稳态误差。
3. 做正弦：0.2、0.5、1.0、2.0 Hz，各 ±10°。普通位置舵机在高频处性能明显下降是正常现象。
4. 同时扰动两个轴，检查轴间耦合、线束拉力和撞限位。
5. 用 NUC 同步记录 CUAV ATTITUDE 和云台遥测：

   ```bash
   python3 tools/cuav_gimbal_monitor.py \
     --gimbal /dev/serial/by-id/usb-STMicroelectronics_STM32_STLink-if02 \
     --mavlink udp:127.0.0.1:14550 \
     --csv gimbal_test.csv
   ```

## 阶段 E：地面整机与飞行试验

1. 拆桨整机通电 10 分钟，覆盖 NUC 高负载、图传发射、舵机往复，确认无 MCU 复位、CUAV 传感器干扰或电源过热。
2. 装桨但不解锁，短时低油门观察振动遥测。若静止角速度噪声显著上升，优先处理桨平衡和机械共振。
3. 首飞采用系留/安全区域、低高度悬停；准备独立云台断电开关。先保持 0°，再做很小的飞行 Roll/Pitch 动作。
4. 检查全程舵机命令是否长期接近 ±45°。接近限位表示机械行程、配平或安装零位不合理。
5. 逐步扩大飞行动作和任务时长，不在同一架次同时更改机械、滤波和增益。

## 故障定位速查

| 现象 | 首查项 | 处理方向 |
|---|---|---|
| `IMU_INIT` | WHO_AM_I、CS、SPI 模式、3.3 V | 检查接线与模块型号，应读到 `0x47` |
| 校准一直不结束 | 机架振动、陀螺偏置、AZ 方向 | 完全静置；打印原始量；放宽阈值只用于诊断 |
| 一 ARM 就撞限位 | 舵机方向、IMU 轴方向 | 断电，逐轴核对符号 |
| 低频来回摆 | 姿态增益过高、机构不平衡 | 降低 `attitude_kp`，先配平 |
| 高频抖动/啸叫 | 角速度增益、齿隙、IMU 振动 | 降低 `rate_kp`，改善结构/滤波 |
| NUC 一接入就复位 | USB 地环路、BEC 瞬态、电源并联 | 重做供电与接地，舵机独立供电 |
| 飞行加速时偏斜 | 加速度倾角误差 | 增强动态加速度抑制或加入 CUAV 前馈/EKF |

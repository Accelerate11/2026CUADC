# 仿真模型与参数标定

## 坐标与口径

轻量环境采用固定局部水平 x/y，z 向上，桶口中心为原点。飞机在二维平面运动，高度在单回合内保持不变。相机输出经标定后转换到该坐标；策略误差表示“桶口减去投放口”，不是桶口减机体中心。默认投放口相对机体中心的偏移 `(0.08, 0) m` 仅为示例。

桶口高度和离地高度必须区分。若飞机的某个参考点离地 1.5 m，桶高 0.3 m，投放口又低于该参考点，则投放高度并不等于 1.5 m。应从同一参考点、同一平面定义重新计算，不能在已经量到桶沿深度后再次机械减桶高。

## 动力学

飞机水平模型：`dv/dt = (v_command - v)/tau + a_disturbance`，其中扰动加速度在本模型中取 `vehicle_wind_gain × wind`。每段常值指令使用解析积分，不依赖容易失稳的显式 Euler 近似。

释放请求通过门控后，飞机在实际机构延迟内继续运动；当前指令在这段时间保持不变。之后载荷从实际投放口出发，继承当时飞机的水平速度。

竖直下落：`t_fall = sqrt(2h/g)`，其中 `g=9.80665 m/s²`。`fall_time()` 还支持非零初始竖直速度，但当前环境只模拟竖直速度为零的近悬停场景。

水平载荷模型：`dv_payload/dt = -k × (v_payload - wind)`。常值风条件下：

`delta_x = wind × t + (v_release - wind) × (1-exp(-k×t))/k`

当 `k=0` 时退化为 `delta_x = v_release × t`。竖直方向没有加入阻力，水平阻力参数也不是某型号水瓶的已知实测值。不能将本模型解释为完整空气动力学。

判断穿过桶口的条件为 `hypot(x_land,y_land) <= bucket_radius - payload_radius - margin`。瓶体长度、倾斜姿态、撞沿和落地弹跳没有建模，`payload_radius` 只是静态有效截面近似。

## 观测模型

每个控制周期生成一帧曝光记录，经固定步数延迟后送达；随机丢帧时保留最后一帧并累积年龄。没有第一帧或年龄超过阈值时观测失效。视觉水平位置和高度有独立高斯噪声；速度观测也有噪声。

默认视觉延迟 1 步、控制周期 0.1 s，即 0.1 s。压力场景为 2 步。默认 4% 丢帧是独立逐帧事件，不等价于真实长段遮挡；`blackout_start_s`、`blackout_duration_s` 可模拟连续失效。当前没有相机视场几何或误识别模型，只适用于上游已锁定且通常可见的目标。

在训练与评估中，隐藏参数和传感噪声使用独立随机数流。相同场景种子能让策略比较获得相同初态和按时间对应的扰动；由于决策不同，飞机轨迹和观测内容当然会不同。

## 参数如何从现有设备取得

| 参数 | 不加传感器的标定方式 |
|---|---|
| 相机到机体、投放口到机体外参 | 机械尺寸测量与现有相机标定，记录坐标定义 |
| 桶口相对误差/深度误差 | 现有 D435i 对固定桶重复观测，与已量尺寸对照 |
| 飞机速度响应 `tau` | 已有 MAVROS 指令、里程计日志拟合阶跃/缓变响应 |
| 释放延迟分布 | 舵机命令时间与现有相机能看清的机构/瓶子动作录像对照 |
| 延迟难以分离的部分 | 作为总释放延迟或更宽的随机化范围，记录不可辨识性 |
| 瓶体有效尺寸与偏移 | 实物尺寸与离线试投记录；不使用实时外部测量系统 |
| 飞行与落点关系 | 既有录像及地面人工结果记录；风作为未知扰动拟合 |

本目录未提供自动从录像标定或自动判读真实落点的程序。若现有相机看不到脱离瞬间，就不能声称已经测得精确机构延迟；应使用总误差拟合并报告区间。

## 已知简化

- 姿态与高度由下层稳定，仿真中姿态固定；实机坐标适配支持四元数变换，但不代表六自由度模型已验证。
- 风在每回合固定，不能覆盖突变阵风。
- 只允许一次不可逆释放；超时不强制投放。
- 视觉置信度有效时固定为 0.9，未拟合真实置信度与误差关系。
- 没有绳索摆动、多瓶互扰、释放失败概率和载荷变化后的飞机动力学。
- 裁判不复现官方分区计分，数据中的 `hit` 只是几何命中。

建议把这些简化作为 Gazebo 和实测验证要逐步补齐的清单，而不是根据轻量仿真的命中率设定实飞机会。

# 投放阶段强化学习方案

## 1. 问题定义

上游任务控制器已经完成起飞、搜索与目标选择，把飞机带到指定桶附近。本方案只研究 `ALIGN → RELEASE` 范围内的水平小幅调整和投放时机。一个回合是一次对准与单瓶释放，桶口固定，当前桶身份由上游锁定。多桶和多瓶可在任务层多次调用此过程，当前模型不学习选桶顺序或总分规划。

先回答可验证的问题：在同样的观测、速度限制、机构和测试场景下，学习策略能否降低落点误差、减少对准耗时，或提高鲁棒性？若固定对准规则已经更好，就保留它。不要把“训练有奖励上升”等同于“比现有控制更好”。

## 2. 不增加传感器的数据边界

| 策略量 | 已有来源 | 当前模拟方式 |
|---|---|---|
| 桶口相对水平位置 `ex, ey` | D435i 检测、深度与标定转换 | 曝光时刻相对位置，加高斯误差 |
| 投放口到桶口高度 `height` | 现有深度及投放口外参 | 恒定真实高度，加观测噪声 |
| 飞机水平速度 `vx, vy` | `/mavros/local_position/odom` | 含噪控制时刻速度 |
| 可用桶口半径 `radius` | 目标类型/现有视觉尺寸与离线设定 | 每场已知配置值 |
| 有效性、置信度、帧年龄 | 视觉输出和曝光时间戳 | 固定有效置信度、随机丢帧及延迟 |
| 回合时间、稳定时间 | 程序状态 | 软件计时，不是新增测量 |
| 上一水平指令 | 原控制器 | 软件控制历史 |

瓶子的真实落点、真实风、真实空气阻力、随机机构延迟和外参误差只存在于环境内部。仿真裁判可读取它们计算奖励，策略不可读取。实机上的离线结果标签可由已有录像、地面人工记录取得；当前版本不自动从视频识别落点，也不要求在线落点传感器。

## 3. 控制与动作

基础对准控制器使用：

`e_now ≈ e_exposure - v_now × observation_age`

`v_command = clip_norm(kp × e_now - kd × v_now + residual, v_max)`

这里是固定水平坐标中的位置误差，所有长度使用米，速度使用米每秒。曝光补偿是一阶近似，真实大幅姿态变化必须由时间同步的姿态和外参变换解决。

Q-learning 有两个动作：继续对准和等待；请求释放。不能改变速度控制律。离散状态由标称预测误差/有效半径、水平速度、是否正在接近、回合进度和门控是否就绪构成。标称预测误差由**观测**和标称释放延迟计算，未读取真实落点。Q 表状态很小，适合快速理解完整闭环，但会丢失方向、历史和细粒度高度信息，不能视为完整 Markov 状态。

PPO 的动作是三个 `[-1, 1]` 数：前两个乘以残差速度限幅，第三个大于 0 表示请求释放。合成速度再次整体限幅。它没有姿态、电机推力、垂直速度、解锁或航线权限。

PPO 观测为 `Observation.vector()` 中固定顺序的 13 维向量；归一化比例写在同一个函数中。实机必须复用同样的顺序与比例。环境整体仍然是部分可观测问题：单帧观测不能确定风和机构延迟。当前 MLP 只带上一指令，不包含完整帧堆叠或循环网络；后续可增加 3–5 帧已有观测历史，这不需要增加传感器。

## 4. 奖励与结束条件

每步：`-0.25 × dt`；若请求释放但被门控拒绝，再扣 `0.05`。

真实释放后：

`reward = (8 if hit else -4) - min(12, (true_error / effective_radius)^2)`

这是**研究用奖励，不是比赛分数**。通过命中奖励、连续落点误差和时间成本，使策略同时考虑命中与效率。PPO 额外扣除 `0.01 × (normalized_rx² + normalized_ry²)`，抑制无意义修正。

释放一次后即终止，不能通过多次投放刷奖励。视觉无效时继续消耗有限时间，但不会释放；达到 12 秒或越过局部范围，按失败扣 8 并终止。这里的 12 秒是任务固有期限，时间进入观测，所以在 Gym 中标为 `terminated=True`，不是外部评估截断。训练未使用落点误差的逐步真值塑形。

不要为了命中率隐藏不投放回合；统计命中率时所有回合都进入分母。奖励权重应根据真实任务时间预算调整，而不是以测试集最高分为目标反复改动。

## 5. 训练路线

1. 无风固定参数，检查坐标、控制方向、延迟和自由落体数量级。
2. 大桶热身，熟悉 Q-learning 的探索与收敛现象。
3. 仓库尺寸的 25 cm 桶，加入域随机化；训练与测试种子分开。
4. 20/15 cm 桶分别训练并交叉测试，分析模型是否只适配某个尺寸。
5. PPO 加小幅水平残差，保持相同基线、动作门控和随机场景。
6. 用真实历史日志缩小模型误差，再迁入 Gazebo/SITL 及影子运行。

本目录已交付第 1–5 步需要的运行入口；初次运行结果不代表第 6 步完成。更可靠的研究比较需要至少 3–5 个独立训练种子、单独验证集选择模型、一次性最终测试集，以及成功率与耗时联合比较。

## 6. 为什么保留现有控制结构

现有飞控已经处理了稳定和姿态闭环；最小版本把学习范围限制在已有数据能够支撑的小问题上。状态机负责目标身份、投放许可、失败退出和多载荷流程。RL 只给候选动作，有利于在同一批日志中逐条比较新旧决定。

当前实验已出现 Q-learning 比简单弹道基线好、比稳定悬停基线差的情况。下一步应先研究延迟与外参标定、基线调优，再判断是否需要增加策略历史或 PPO 残差。不能假设增加网络规模就能补偿不可观测的风和机械误差。

# 2025留给后人的话

## 1. 解决起飞偏移问题

可从以下两个方向进行改进：

- 使用外置罗盘
- 使用双 RTK 定向

## 2. 提升视觉识别效率

- 视觉识别部分考虑采用**多圆识别**方法，提高整体识别效率。

## 3. 优化结构设计

- 结构连接件建议改为**两部分可拆卸结构**。
- 提高装配、拆卸、维护和运输的便利性。

## 4. 重点解决信号传输问题

重点关注飞行过程中各类无线及有线信号的稳定性，包括但不限于：

- 数传干扰
- 网络波动
- 路由器信号稳定性
- RTK 信号稳定性
- 机载电脑回传稳定性

上述问题可能影响：

- RTK 定位与定向
- 飞控数据传输
- 机载电脑与地面端通信
- 实时图像及状态信息回传

可考虑引入 **4G 模块**，作为通信链路的补充或冗余方案，提高整体通信稳定性。

## 5. 优化验证方式

- 部分代码可使用**小飞机在室内进行验证**。
- 减少大型无人机反复测试带来的时间成本。
- 降低场地需求和测试成本。
- 提高代码调试与功能验证效率。

## 6. 提升飞行器本体控制效果

目前主要采用基础 PID 控制，后续可进一步研究其他控制方法，提高飞行控制效果，例如：

- PID 参数进一步优化
- 串级 PID
- 前馈控制
- 自适应控制
- LQR 控制
- MPC 模型预测控制
- 抗扰控制

重点提升：

- 定点悬停精度
- 抗风能力
- 轨迹跟踪精度
- 起飞与降落稳定性
- 外部扰动下的控制鲁棒性

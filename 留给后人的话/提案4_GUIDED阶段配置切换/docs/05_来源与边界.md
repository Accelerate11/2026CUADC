## 官方接口依据

以下资料于 2026-10-13 核对，属于官方协议、官方源码或项目维护者文档。`Copter-4.5` 和 MAVROS `ros2` 是分支引用，后续可能变动；实机适配时应锁定完整版本及提交。

| 依据 | 本提案采用的结论 |
| --- | --- |
| [ArduPilot GUIDED 指令](https://ardupilot.org/dev/docs/copter-commands-in-guided-mode.html) | GUIDED 支持专用改速命令以及位置、速度等目标接口 |
| [Copter 4.5 GUIDED 源码](https://raw.githubusercontent.com/ArduPilot/ardupilot/Copter-4.5/ArduCopter/mode_guided.cpp) | 初始化默认约束与运行速度更新接口不同，参数写入不是统一刷新动作 |
| [Copter 4.5 参数处理](https://raw.githubusercontent.com/ArduPilot/ardupilot/Copter-4.5/libraries/GCS_MAVLink/GCS_Param.cpp) | 普通参数写入进入保存路径 |
| [MAVROS ParamSetV2 定义](https://raw.githubusercontent.com/mavlink/mavros/ros2/mavros_msgs/srv/ParamSetV2.srv) | 使用 ROS 2 ParameterValue，响应不提供失败原因字段 |
| [MAVROS 参数插件](https://raw.githubusercontent.com/mavlink/mavros/ros2/mavros/src/plugins/param.cpp) | 参数客户端读本地缓存；写入逐项确认；不支持设备端原子整组写入 |
| [MAVLink 参数协议](https://mavlink.io/en/services/parameter.html) | 单项传输与确认，不能把参数列表当作同一时刻整组替换 |
| [MAVLink DO_CHANGE_SPEED](https://mavlink.io/en/messages/common.html#MAV_CMD_DO_CHANGE_SPEED) | 改速速度字段使用 m/s，并有独立速度类型 |
| [Copter 4.5 命令处理](https://raw.githubusercontent.com/ArduPilot/ardupilot/Copter-4.5/ArduCopter/GCS_Mavlink.cpp) | 水平、上升、下降改速由不同飞行模式接口处理 |
| [Copter 4.5 航点参数](https://raw.githubusercontent.com/ArduPilot/ardupilot/Copter-4.5/libraries/AC_WPNav/AC_WPNav.cpp) | 该版本 WPNAV 速度与加速度采用厘米单位 |
| [ArduPilot Lua 参数接口](https://ardupilot.org/dev/docs/common-scripting-parameters.html) | 运行值设置与设置并保存是不同接口 |

Lua 仅作为后续方案：若需要运行期间临时值，可研究飞控脚本，但必须写明恢复逻辑、生效路径和退出策略。本交付没有 Lua 脚本，也没有实现由 Lua 执行的飞控配置恢复。

## 本次证据范围

1. 本次新增的是阶段参考轨迹、切换门控及默认关闭的异步飞控事务；原工作空间的历史验证属于基线证据。
2. 本次验证是否完成编译、执行了哪些回归，以 [04 · 验证记录](04_验证记录.md) 为准。没有同版本 SITL 和实飞记录时，不能由离线测试推导空中稳定性。
3. 机载参考限速不等于机体严格限速；接口确认不等于控制器已采用，不等于物理响应合格。
4. 不知道实机完整 ArduCopter 版本、完整参数导出、载荷质量、重心、外参实际安装值。Copter 4.5 的解释不是对实机版本的识别。
5. 没有新传感器确认瓶子脱离、载荷重量或落桶。两瓶完成标签由原任务流程推进；原投放强制回退策略仍然存在。
6. 飞控写入不是原子事务，未知超时可能存在迟到执行，客户端取消不能撤回链路上已经发送的命令。
7. 默认七组数值是研究配置；没有宣称它们达到比赛成绩、降低能耗或提高投放命中率。

# 02 · 参数与 MAVROS 接口

## 配置位置与默认开关

主任务配置保存在工作空间的 `full_mission/mission.yaml`、`drop_only/mission.yaml` 和包内 `src/cuadc_full_mission_20260803/config/mission_real.yaml`。配置必须放在 `cuadc_full_mission_node.ros__parameters` 下；新参数由任务节点启动时读取，不应当作任意 ROS 参数热更新接口。

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `flight_enable` | `false` | 任务飞行总开关 |
| `auto_arm_on_guided` | `false` | 是否在 GUIDED 准备完成后请求自动解锁 |
| `guided_local_profiles_enabled` | `true` | 使用阶段参考轨迹与视觉增益配置 |
| `guided_fcu_enabled` | `false` | 启用飞控改速与可选参数事务 |
| `guided_fcu_param_switch_enabled` | `false` | 启用白名单飞控参数写入 |
| `guided_fcu_confirmed_firmware` | `""` | 人工核对的完整固件号；参数实验要求 `4.5.<patch>` |
| `guided_fcu_allowlist` | `[]` | 明确允许写入的参数名 |
| `guided_fcu_timeout_s` | `15.0` | 每项飞控异步操作等待预算，秒 |
| `guided_fcu_retries` | `1` | 明确失败的有限重试；范围 0–3，未知结果不重试 |
| `guided_fcu_tolerance` | `0.00001` | 参数浮点回值比较容差 |

`guided_fcu_confirmed_firmware` 是操作者的声明，不读取设备并证明固件版本。填写 `4.5.7` 等示例只满足版本形式，不能自动完成兼容性验证；必须先导出实机版本和参数，并核对同版本源码。飞控功能关闭时，本地阶段切换仍运行，不发送新增飞控改速或 PID 写入。`guided_fcu_enabled=true` 要求 `guided_local_profiles_enabled=true`，否则配置检查拒绝起飞，因为飞控事务必须使用本地稳定门控；两个开关都关闭时沿用原 V16 参考路径和视觉倍率 1。

空白名单和空参数组由 C++ 中声明的有类型空数组默认值提供。**在 Humble 的任务 YAML 中省略这些空字段，不要显式写 `[]`**；无元素 YAML 数组可能成为 `NOT_SET`，从而影响配置读取。需要参数实验时才填写有内容的名称和值列表。

## 七组阶段配置

每组前缀为 `guided_profiles.<阶段>`，字段为 `speed_xy_m_s`、`acceleration_xy_m_s2`、`speed_z_m_s`、`acceleration_z_m_s2`、`vision_gain`、`fcu_param_ids`、`fcu_param_values`。

阶段表和实验开关在节点启动时读入，任务运行时自动选择已加载的配置。修改 YAML 后需重新启动；本版没有实现通过 `ros2 param set` 在线重载这些配置的回调。飞控参数实验则由任务切换事务在运行时发送至 MAVROS，两者是不同接口。

| 阶段 | 水平速度 m/s | 水平参考加速度 m/s² | 垂直速度 m/s | 垂直参考加速度 m/s² | 视觉倍率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| `cruise` 巡航 | 3.00 | 1.00 | 0.70 | 0.50 | 1.00 |
| `search` 搜索 | 1.25 | 0.60 | 0.50 | 0.40 | 1.00 |
| `approach` 接近 | 1.50 | 0.60 | 0.50 | 0.40 | 0.80 |
| `align` 对准 | 0.375 | 0.40 | 0.16 | 0.25 | 0.60 |
| `release` 投放 | 0.15 | 0.25 | 0.16 | 0.25 | 0.35 |
| `recon` 侦察 | 1.50 | 0.80 | 0.70 | 0.50 | 1.00 |
| `return` 返航 | 3.00 | 1.00 | 0.70 | 0.50 | 1.00 |

这些是**第一版可改的研究默认值**，不是原机实飞标定，也不是比赛最优参数。原任务路径自己的限速与阶段上限共同约束位置参考，阶段数值不是指令目标下限。四个运动值必须有限且大于零，`vision_gain` 必须大于零且不超过 1；后者缩放上位机既有视觉位置修正，不能与 `ATC_RAT_*` 飞控 PID 增益混用。所有阶段的 `fcu_param_ids / fcu_param_values` 默认为空数组。

只启用本地配置的 YAML 示例：

```yaml
cuadc_full_mission_node:
  ros__parameters:
    flight_enable: false
    auto_arm_on_guided: false
    guided_local_profiles_enabled: true
    guided_fcu_enabled: false
    guided_fcu_param_switch_enabled: false
    guided_profiles.align.speed_xy_m_s: 0.375
    guided_profiles.align.acceleration_xy_m_s2: 0.40
    guided_profiles.align.speed_z_m_s: 0.16
    guided_profiles.align.acceleration_z_m_s2: 0.25
    guided_profiles.align.vision_gain: 0.60
```

开启 PID 实验时，名称和值数组必须等长，名称必须同时通过固定允许集和操作者白名单。固定允许集只有 `ATC_RAT_RLL_P/I/D`、`ATC_RAT_PIT_P/I/D`、`ATC_RAT_YAW_P/I/D` 共九项；不能把 `WPNAV_SPEED`、`FRAME_CLASS` 或其他参数塞进该接口。本提案不提供可直接套用的增益数值。

## 切换门控参数

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| `guided_switch_timeout_s` | 20.0 s | 一次阶段门控总预算，含飞控事务等待 |
| `guided_switch_stable_s` | 0.5 s | 实际低速连续满足时间 |
| `guided_switch_nav_max_age_s` | 0.3 s | 导航消息最大允许年龄 |
| `guided_switch_horizontal_speed_m_s` | 0.25 m/s | 实际水平速度门槛 |
| `guided_switch_vertical_speed_m_s` | 0.15 m/s | 实际垂直速度门槛 |

`guided_fcu_timeout_s` 与总门控预算不是相加的无限等待。参数拉取、读取、逐项确认都需要时间；启用较长事务应在 SITL 中校准预算，并验证触发总超时后的处理。无需为了刷新参数切出再切回 GUIDED。

## 实际 ROS 2 接口

| 接口 | 类型 | 使用方式 |
| --- | --- | --- |
| `/mavros/setpoint_position/local` | `geometry_msgs/msg/PoseStamped` | 原任务持续位置参考 |
| `/mavros/local_position/odom` | `nav_msgs/msg/Odometry` | 参考坐标和实际运动门控 |
| `/mavros/cmd/command` | `mavros_msgs/srv/CommandLong` | 可选改速命令 178 |
| `/mavros/param/pull` | `mavros_msgs/srv/ParamPull` | 事务前 `force_pull=true` 拉取 |
| `/mavros/param/get_parameters` | `rcl_interfaces/srv/GetParameters` | 拉取后通过标准参数客户端读取缓存快照 |
| `/mavros/param/set` | `mavros_msgs/srv/ParamSetV2` | 逐项浮点写入和回值核对 |

这些名称以本工作空间默认 MAVROS 命名空间为准，先通过 `ros2 service list -t` 核对部署。`ParamSetV2` 的值采用 `rcl_interfaces/ParameterValue`，不是 ROS 1 `ParamSet` 请求。[官方服务定义](https://raw.githubusercontent.com/mavlink/mavros/ros2/mavros_msgs/srv/ParamSetV2.srv)

事务读取的 `get_parameters` 是 MAVROS 缓存，故必须先完成强制拉取；读到数值不能单独证明飞控刚收到一次实时读请求。MAVROS 设备侧原子参数写入接口明确不支持。[MAVROS 参数插件](https://raw.githubusercontent.com/mavlink/mavros/ros2/mavros/src/plugins/param.cpp)

## 单位、确认与恢复

改速命令使用 `command=178`，`param1=1` 地速、`2` 上升、`3` 下降，`param2` 为 **m/s**。本版 helper **仅发送 `param1=1` 的水平速度请求**；垂直配置由本地参考层使用，没有实现飞控上升/下降速度命令。命令不是写 `WPNAV_SPEED`。MAVLink 对该命令定义了独立的速度和速度类型字段。[MAVLink 命令定义](https://mavlink.io/en/messages/common.html#MAV_CMD_DO_CHANGE_SPEED)

原说明中 Copter 4.5 的 `WPNAV_SPEED` 为 cm/s；`100` 对应 1 m/s，而不是 100 m/s。当前工作空间没有把反复写 `WPNAV_SPEED` 用作参考轨迹限速。Copter 4.5 的 GUIDED 初始化及 `set_speed_xy()` 更新路径不同，参数表写入不等于运行控制器刷新。[Copter 4.5 GUIDED 实现](https://raw.githubusercontent.com/ArduPilot/ardupilot/Copter-4.5/ArduCopter/mode_guided.cpp)

| 事务结果 | 本版处理 |
| --- | --- |
| 命令 `success=true` 且结果接受 | 此项接口确认，继续后续项 |
| 参数 `success=true`、浮点类型正确、回值匹配 | 此项确认，继续下一参数 |
| `success=true` 但参数回值不匹配 | 有限重试，耗尽后按快照顺序恢复可能触及项，最终仍失败 |
| 参数 `success=false` | 原因不可区分，按结果未知锁存失败，停止追加写入 |
| 命令 `success=false`、`result=0` | 可能为 MAVROS 内部超时，按未知结果处理 |
| 客户端超时、接管或取消 | 停止后续请求；已发送请求可能完成，不能声称撤销 |
| 恢复失败或恢复超时 | 保持失败状态，落地后读取飞控并人工核对 |

失败锁存后，不能靠重新请求同一阶段自动恢复运行；重启程序也不证明飞控参数回到原值。正式实验结束后另行导出飞控参数与飞前快照比较。普通 `PARAM_SET` 在 Copter 4.5 中调用保存路径，不属于默认不持久化的临时参数。[Copter 4.5 参数保存实现](https://raw.githubusercontent.com/ArduPilot/ardupilot/Copter-4.5/libraries/GCS_MAVLink/GCS_Param.cpp)

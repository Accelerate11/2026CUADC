# 搜索阶段目标坐标锁定

搜索阶段与细对准使用不同的数据策略。搜索阶段不使用图像边缘门限，
因为有限航线可能让桶出现在画面上方或下方。

每条轨迹保存最近 15 个世界坐标样本，位置使用 X/Y/Z 中位数；位置离散度
使用样本到中位数的径向中位数计算。新目标至少累计 6 个不同检测帧、位置
离散度不超过 0.20 m，并满足原有置信度、直径离散度和轨迹门限，才可能
进入粗对准计划。候选再按确认数量、置信度、位置离散度、直径离散度综合评分。

锁定到粗对准计划时保存这个鲁棒坐标快照。进入细对准后仍保留当前逻辑：
最新有效检测会直接更新活动目标，用于实时纠偏和投放前对准。

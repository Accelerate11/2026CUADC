# 复现说明

这里将“源码一致”“软件能编译运行”“实际飞机复现”分开记录，避免把通过单元测试理解成已经完成外场验证。

## 本包已经提供

完整V16任务与视觉源码、模型权重、任务参数、相机与投放口原外参、原时间同步设置、编译脚本、启动入口、标定工具、舵机检查、复盘工具及测试。无需下载本项目的其他闭源组件，也没有加密核心代码。

每次拿到发布包，先运行 `python3 scripts/validate_source.py` 或在Linux中运行 `sha256sum -c SHA256SUMS`。源码有修改时，校验失败是正常提示；不要用删除校验步骤的方式掩盖版本差异。

## 环境记录

原包保存了部分Python版本约束，没有完整机载环境快照。环境目录区分原始依赖记录、OpenVINO模型导出版本和本次验证环境；不会把这三者合并声称为原比赛环境。

在实际机载环境准备好并验证后，保存：

```bash
python3 scripts/capture_environment.py --output log/environment.json
python3 -m pip freeze > log/pip-freeze.txt
dpkg-query -W > log/dpkg-versions.txt
```

同时归档飞控固件版本、飞控参数导出、相机固件、Intel驱动版本、本轮路线和运行参数。这样后续换机器时才有完整对照。本包没有原飞机固件及参数导出，也没有原始训练集、标注集和训练脚本；模型推理可复现，训练过程不能凭权重还原。

## 逐级验证

1. **源码层**：校验清单、Python语法、Shell语法、模型完整性。
2. **软件层**：`build_onboard.sh`、`verify.sh`，检查实际安装目录和launch入口。
3. **模型层**：环境检查工具读取随包模型并用合成输入验证CPU推理，结果不代表检测精度；IntelGPU需在目标机器上另测。
4. **硬件层**：单独验证串口、D435i曝光时间、外参、投放口、舵机、RTK路线与人工接管，再进入完整任务测试。

此包未附经过本次验证的SITL全流程场景。原项目的仿真目录需要单独适配V16接口；本次也没有连接飞机重飞，因此没有将旧日志中的实机结论写成本次验证结果。

## 自动回归

压缩包外层提供 `.github/workflows/v16.yml`。将外层作为独立Git仓库时可直接采用；合入现有2026CUADC仓库时，把workflow复制到仓库根 `.github/workflows/`，并将 `CUADC_WORKSPACE` 改为实际工作区相对路径。

该workflow执行CPU环境下的源码检查、编译和离线回归，不连接相机或飞控。ROS容器标签及apt仓库会更新，具体已验证软件版本见本包记录；需要离线长期复现时，应另行保存通过验证的系统镜像和依赖缓存。

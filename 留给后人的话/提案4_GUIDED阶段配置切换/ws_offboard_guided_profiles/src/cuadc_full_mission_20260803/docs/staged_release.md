# 分段投放判定

full_mission 和 drop_only 的主节点配置启用 staged_release_gate。
计时原点沿用原先下降完成判定：实际高度进入投放高度 ±5cm；不是进入
RELEASE 状态的时刻。全过程继续视觉检测和原有限速下的水平对准。

- 0–0.5s：禁止投放，不累积四帧记录。
- 0.5–4s：第一帧误差 ≤3cm，随后连续第2–4帧误差 <5cm；期间每个
  控制周期检查实际水平速度 <0.1m/s。违反速度、检测失效或误差条件
  则清零，重新等第一帧。使用曝光时间区分新帧，不重复计数，也不采用
  前0.5秒曝光但延迟到达的图像。
- 4–6s：任意一帧新鲜的新图像误差 ≤3cm 即投，不再要求速度门限或四帧。
- ≥6s：强制投放；之前没满足条件不会延长截止时间。

新鲜观测沿用≤0.5秒要求，必须对应最新处理的有效检测帧。没有新增
垂直速度、姿态或稳定持续时长门限。飞控接管/故障等原有退出逻辑不变。
速度、高度、ALIGN超时、舵机PWM与保持时间均未修改。

日志正常投放区分 gate=four_frames / relaxed_single_frame，记录计数、
误差、实际速度和经过时间；强制投放保留 VISUAL_RELEASE_TIMEOUT 标记。
关闭该开关的其他入口仍沿用 release_stabilization_s 的旧逻辑。

# 从零开始的硬件与电子常识

本篇从“电从哪里来、沿哪里流、信号怎样被理解”开始，学习读规格、画接线图、使用仪表和排查故障。不要求先有飞机、飞控或编程经验。

阅读目标是能解释一条连接为什么成立，并能用测量检验自己的解释。设备名称和连接器外形都不能代替电气规格。文中的数值只属于注明条件的例题。

纸面计算和断电识线可以先做；第一次通电实验使用明确限流的低压直流电源与电阻负载。动力电池、电机和带载机构另有装配与操作要求，不能把小电阻实验直接扩大为整机上电。

## 1. 用一条回路认识硬件系统

一盏灯能亮起来，至少需要电源、负载和闭合的电流路径。

```text
电源正端 ── 导线 ── 负载 ── 导线 ── 电源负端
   │                                      │
   └──────── 电源内部完成能量转换 ──────────┘
```

电源把其他形式的能量转换为电能，负载再把电能变为光、热、运动或计算活动。导线不是抽象的“连接成功”：它也有电阻、寄生电感、接触点和允许电流。

只接电源正端、没有可用回流路径，不能形成期望的持续供电回路。对于有信号输入的模块，还要问信号相对于哪个参考点测量。

机器人系统可以先画成四条链：供电链、信号链、机械链、观察链。舵机不动时，这四条链都可能提供线索。

**小练习：**画出“电源—开关—电阻—回到电源”的路径，标出开关断开时哪里仍可能有电压。

**答案：**没有电流不等于每处电压都为零。开路开关的两侧可以存在电势差。

## 2. 电压是两个点之间的差

电压的单位是伏特V。说“A点是5 V”，实际上省略了相对于哪个参考点。完整说法是“A相对于B为5 V”。

将B定义为0 V后，可以写`V_A=5 V`。这个0 V是本电路的参考，不一定与另一个电源、机壳或建筑保护地相同。

直流例题中，红表笔接A、黑表笔接B，读数为`V_A - V_B`。交换表笔，理想读数改变符号。负号通常表示参考方向相反，不直接表示电源损坏。

```text
 A点 o ───── 负载 ───── o B点
      红表笔       黑表笔
          电压表并接两点
```

初学时每一个电压读数都写成“位置、参考、数值、单位”。例如“模块输入正端相对模块输入负端：4.93 V”。

## 3. 电流是流过某一截面的速率

电流单位是安培A，常见换算为`1 A = 1000 mA`。传统电流方向以正电荷运动方向定义，金属中电子运动方向与它相反；本教程使用传统方向。

电源标注“5 V、3 A”，通常表示在规定条件下能维持相应输出电压，并允许一定输出电流。它不会对每个负载强行灌入3 A。

一个5 V、1000 Ω的理想电阻负载，电流约为5 mA；换成具有电机与驱动器的模块，电流可能随动作、负载和启动过程变化。

**关键区别：**电源的电流能力、实际工作电流、启动峰值和短路电流是不同的量。规格表中的“最大值”也要看它是工作上限还是绝对最大额定值。

**小练习：**两个模块各用0.3 A，可以直接断言1 A电源足够吗？

**答案：**还缺启动与动作峰值、输出降额、线损和允许压降；只能先算出平均需求的一部分。

## 4. 电阻、压降与发热

对近似欧姆电阻，`V = I R`。R的单位是欧姆Ω。

假设来回导线与连接器的等效电阻合计为0.08 Ω，电流2 A时：

```text
压降 ΔV = I R = 2 × 0.08 = 0.16 V
发热 P = I² R = 2² × 0.08 = 0.32 W
```

电流变成5 A后，压降为0.40 V，发热为2 W。发热按电流平方增长，这解释了为什么空载正常的细线，在动作峰值时可能出问题。

真实连接器的接触电阻可能随插合状态、氧化和温度改变。单次静态测量正常，不能证明振动和大电流下仍正常。

电阻器也有额定功率。5 V加在1000 Ω上，功耗为`5²/1000 = 0.025 W`；纸面例题选择额定0.25 W电阻，可把功率计算和额定值区分开。实际还应考虑环境与器件降额。

## 5. 功率与能量不是一回事

直流稳态近似下，功率`P = V I`，单位瓦W。能量是功率对时间的积累，恒定功率下`E = P t`。

10 W设备工作2小时，消耗约20 Wh。只知道“耗电10 W”无法判断能运行多久，还需要可用能量。

电池容量Ah主要表示电荷量，不能直接比较不同电压电池的能量：

| 纸面电池 | 标称容量 | 按标称电压估算能量 |
|---|---:|---:|
| 7.4 V | 2 Ah | 14.8 Wh |
| 14.8 V | 2 Ah | 29.6 Wh |

这只是能量量级估算。实际放电电压会变化，可用能量还受温度、电流、截止条件和老化影响。

**练习：**12 W负载从理想24 Wh电源取能，理论时间是多少？

**答案：**2小时；加入转换损耗和未使用余量后会更短，不能把2小时直接作为任务时间。

## 6. 串联与并联

串联支路中流过相同电流；理想电阻串联时总电阻相加。并联支路两端电压相同，电流在支路间分配。

对两个正电阻，串联有`R总 = R1 + R2`，并联有`1/R总 = 1/R1 + 1/R2`，也就是`R总 = R1 R2 / (R1 + R2)`。并联时把每支路的`I = V/R`相加，就能得到倒数关系。

```text
串联：  +5V ── R1 ── R2 ── GND

并联：  +5V ──┬── R1 ──┬── GND
              └── R2 ──┘
```

两个1000 Ω电阻串联接5 V，总电流2.5 mA，各分担约2.5 V；并联后每支路约5 mA，总电流约10 mA。

电阻分压器可以演示比例关系，但不能自动成为稳定电源。接入新的负载，相当于改变电阻网络，输出电压会改变。

电池串并联涉及单体一致性、连接方式和保护，不能照搬电阻实验。也不能未经允许把两个稳压输出正端直接并联，期望电流自然平均分配。

### 阶段练习A：把数字写完整

1. 500 mA等于多少A？
2. 5 V负载消耗2 W，平均电流约多少？
3. 同一连接点电阻不变，电流翻倍，发热怎样变化？

答案依次为0.5 A、0.4 A、4倍。每个答案都只适用于题设的直流近似条件。

## 7. 认识电池标签

常见标签包括化学体系、串联节数、标称电压、容量、充放电限制和连接器。先读化学体系，再读数字。

对常见的标准充电上限4.2 V锂聚合物单体，3.7 V常用作标称值；这不是所有锂电池的统一参数。LiHV、磷酸铁锂及其他电芯必须按各自说明处理。

S表示串联节数。若题设为6节上述单体，则标称电压约22.2 V，充满时约25.2 V。选择设备输入范围时，不能只检查22.2 V。

容量为2 Ah、标签放电倍率为20C时，乘积给出40 A这一标签量级。它不能独立证明电池在实际散热、寿命与压降条件下可持续提供40 A。

充电倍率和放电倍率不是同一个规格。充电器必须匹配电池化学体系、节数和制造商允许电流；不能根据插头能插入决定充电模式。

## 8. 负载一动就重启，可能发生了什么

电池、导线和连接器都存在阻抗。负载电流快速增加时，输入电压可能下降，稳压器也可能因限流或动态响应暂时掉压。

```text
机构启动 → 电流增加 → 电源或线束压降增加
        → 计算模块输入越过允许范围 → 复位
```

这是一条假设链，不是所有重启的定论。软件异常、过温和接口复位也可能造成类似症状。

设计验证时，同步记录电源端与负载端电压、动作时刻和复位事件。普通万用表可能看不到很短的尖峰，显示最小值也受采样与捕获能力限制。

增加电容能否改善，要依据瞬态持续时间、电源稳定性、ESR与布线分析。ESR是电容的等效串联电阻，用来描述实际电容中的一部分损耗与瞬态压降；它不等于电容容量。随手加一只“大电容”不能替代电源预算。

## 9. 稳压器与BEC

稳压器把输入转换为负载需要的输出。BEC在模型设备中常指给接收机或舵机等低压部分供电的电路；名称不能说明具体性能。

选择时至少核对输入范围、输出电压、连续与瞬态电流、效率、散热、保护和输出纹波。降压、升压和升降压结构的输入输出条件不同。

例题：负载为5 V、2 A，输出功率10 W，假设转换效率90%、输入15 V，则输入平均电流约为`10 / (0.90 × 15) = 0.741 A`。

输入电流与输出电流不同。把输出2 A直接加进15 V主电源的电流表，会混淆电压域。

线性稳压的热损耗近似为`(V_in - V_out) I`。若由12 V降到5 V并输出1 A，损耗约7 W；这个例子用于理解热预算，不是器件选型建议。

## 10. 画一张真正可用的供电图

方框图先表达支路，再补具体针脚。下面只表示一种架构，不是任何具体板卡的接线图。

```text
电源 ── 总连接/保护 ──┬── 动力支路 → 电调 → 电机
                     ├── 稳压A → 计算模块
                     ├── 稳压B → 传感器
                     └── 稳压C → 机构负载

每条支路都要画出返回路径、线束和接插件。
```

图上至少写：电压范围、预期电流、线束标识、针脚方向、保护器件、开关位置与测量点。不能只写“接5 V”。

飞控核心供电与舵机电源轨不一定相通；USB能让飞控显示状态，不代表输出轨已经给舵机供电。不同硬件结构必须查对应手册。[飞控输入输出说明](https://ardupilot.org/copter/docs/common-flight-controller-io.html)

## 11. 地、回流与屏蔽

GND是电路参考与回流网络，保护地是人身与设备保护体系中的概念，屏蔽层主要用于管理电磁耦合。它们可能按设计连接，但不能随意视为同一根线。

单端信号接收器比较“信号相对于本机参考”的电压。两个模块没有合适参考关系时，发送端的高电平在接收端可能没有预期含义。

对于常见非隔离低压单端接口，需要按设计建立信号参考；大电流回流不宜经过细小信号地线。隔离接口和差分总线则按对应收发器与系统要求处理，不能套用“所有地都短接”的口诀。

供电图中可以用不同颜色或线型标出动力回流、计算模块回流和信号参考，检查它们在哪里汇合。电路物理布局也影响瞬态耦合。

## 12. 连接器与线束

插头看起来相似，不说明节距、锁扣、额定电流、针脚顺序和极性相同。JST也是一组系列的品牌名称，不能仅凭“JST口”决定配线。

查针脚图时先确认观察方向：看插座正面、插头线端或PCB顶视图，左右顺序可能不同。以图中的编号和机械基准核对，不凭照片印象。

颜色只是辅助。维修过的线束、转接线和不同厂商产品可能采用不同颜色约定。

| 线束编号 | 两端型号与针号 | 每芯用途 | 额定要求 | 断电验证 |
|---|---|---|---|---|
| 自行填写 | 标明观察方向 | 电源/地/信号 | 电压、电流与环境 | 通断与极性 |

导线应有适当应力释放，避免插头承担拉力。热缩管绝缘不能修复内部压接不良，胶固定也不能替代可靠电接触。

## 13. 逻辑电平与接口协议

逻辑电平说明怎样用电压区分0和1；协议说明这些0和1按什么时序和结构解释。两者必须分别兼容。

接收端的高低判定阈值、输入容限与绝对最大额定值都应查数据手册。3.3 V和5 V模块之间是否可直接连接，不能只根据“都是数字信号”判断。

电平转换器、串口协议转换器和连接器转接线也不同。只把插头换形状，不会自动改变电压、编码或时序。

**例题：**某模块用UART协议、RS-232电气接口，另一模块是3.3 V CMOS UART。两者能否只交叉TX与RX？

**答案：**不能。UART描述的字符时序不消除RS-232与CMOS电气层差异，需要匹配的收发器和接口设计。

## 14. UART：从两根数据线到完整链路

常见全双工UART连接中，发送端TX接接收端RX，另一个方向同理，并按设计建立参考地。具体端口标名有时以外部设备方向命名，因此仍应查针脚定义。

通信双方需要匹配波特率、数据位、校验位、停止位，以及流控方式。8N1表示8数据位、无校验、1停止位，另有起始位。

若每字符占10个串行比特，则115200 bit/s的理想字符率约11520 byte/s，尚未扣除协议包头、处理间隙和重传。

```text
物理插接 → 电气电平 → 串行参数 → 消息格式 → 业务语义
```

能读到一串字节不表示消息完整；字节完整也不表示单位与时间戳正确。逐层检查会比同时修改所有参数更有效。

## 15. I²C与SPI：短线也有电气条件

I²C通常用SDA传数据、SCL传时钟，具有寻址机制。标准接口使用开漏/开集电极式拉低和上拉网络，线上电压由设计中的上拉电源与器件能力共同决定。

“开漏”在这里可以先理解为器件负责把线拉低，不主动把线推高；释放后，由上拉电阻使线趋向上拉电源电压。电阻和总线电容共同影响恢复到高电平的速度。

多个模块都自带上拉电阻时，并联后的等效阻值会降低；总线电容也影响上升时间。因此“线能插上、地址不同”还不足以保证通信。[NXP I²C规范](https://www.nxp.com/docs/en/user-guide/UM10204.pdf)

SPI常见时钟、数据输入输出和片选线。时钟极性、采样相位、位序与片选规则需要双方匹配；不能只设置相同频率就宣布兼容。

| 需要核对 | I²C例子 | SPI例子 |
|---|---|---|
| 电气 | 上拉电压、拉低电流、总线电容 | 输入容限、输出驱动、线长 |
| 时序 | 模式、时钟、上升时间 | CPOL/CPHA、最高频率、片选时序 |
| 协议 | 地址、寄存器与读写顺序 | 寄存器、命令字、返回布局 |

这两类接口经常用于板内或短距离模块通信。是否适合某条长线，应依据电气设计与实测，不能仅凭低速就认定可靠。

## 16. CAN：差分信号仍需完整设计

CAN常通过收发器在CAN_H和CAN_L之间传输差分信号，抗扰机制不代表可以忽略共模电压、参考连接或布线。

差分电压是两线之间的差；共模电压描述两线相对于接收端参考一起抬高或降低的部分。即使差分值正常，超过收发器允许共模范围仍可能无法工作或损坏。

高速CAN典型物理总线采用两端终端电阻。常见120 Ω是该类总线的设计值，不是所有名称含CAN的接线都可以无条件照抄。拓扑、支线长度、速率与收发器应一起确定。

```text
终端 ── 主干 ── 节点 ── 节点 ── 主干 ── 终端
```

对断电、隔离且仅有两个120 Ω终端并联的理想网络，H与L间直流电阻约60 Ω。实际读数还会受到节点与保护电路影响；不要在有电状态下用电阻挡寻找这个数字。

节点ID不冲突只是协议条件之一。还要核对波特率、终端、H/L、供电和固件中的上层协议。CAN、DroneCAN与其他上层协议不是同一层概念。

## 17. PWM与舵机：脉宽、频率和占空比

PWM的字面含义是脉宽调制，但不同设备对脉冲的解释不同。调光、电机驱动和传统位置舵机不能混为一种接口。

对许多传统位置舵机，位置主要由高电平脉宽表示。1.5 ms常见于中立位置附近，但可接受脉宽、重复频率、电压和机械行程必须查具体型号。[舵机接口说明](https://www.pololu.com/blog/16/electrical-characteristics-of-servos-and-introduction-to-the-servo-control-interface)

纸面计算：50 Hz周期为20 ms，1.5 ms脉宽占空比7.5%；若周期为10 ms，同样脉宽占空比15%。这说明固定脉宽与固定占空比不是同一种控制方式，不能据此把实际舵机任意改成100 Hz。

舵机的供电、信号、机械负载都需要分别检查。命令给到释放位置，不代表挂钩已松开；空载摆动正常，也不代表带载电流和机构余量足够。

## 18. 电机、电调和螺旋桨

电调将电源能量按控制与换相策略送给电机。飞控发出的目标通常是上层意图，不等于直接测得的转速或推力。

无刷电机的KV常以rpm/V表示，主要用于描述转速常数的量级，不能理解为“每伏产生多少推力”。带桨转速还受扭矩、电流、电池压降和效率影响。

螺旋桨直径、桨距、材料和旋向会改变负载。只换大桨，可能同时改变电流、发热、振动和控制响应，不能只看悬停油门。

DShot等数字接口与传统脉冲接口具有不同编码与配置。数字传输能表达更明确的命令，也不能自动提供推力真实性或机械安全。

认识电机映射与旋向时先拆桨。第一次电子基础练习不需要让动力系统旋转；本篇的通电实验均可用电阻完成。

## 19. USB与“设备偶尔消失”

USB同时涉及供电、数据链路、主机控制器、驱动与应用。能给设备充电的线，不一定具备所需数据能力；插口颜色也不能完整证明实际链路速率。

多个相机或其他高吞吐设备可能共享同一上游链路。增加一个集线器，不能凭空增加上游带宽。

故障时分开记录：设备是否仍枚举、供电是否稳定、内核是否报告复位、应用是否持续取帧、存储是否阻塞。只看到画面停止，尚不能确定相机断电。

Linux中的`lsusb`和内核日志可以观察枚举与复位，但它们不能代替电压测量或USB协议分析。相关命令在[Linux与开发工具篇](Re0_从零开始的Linux与开发工具.md)中练习。

2. CAN总线通信失败，改节点ID能排除全部问题吗？
3. 舵机信号线上有脉冲，能证明舵机供电正常吗？

## 20. 万用表先读哪里

第一次拿到仪表，先找到型号手册、COM端、电压电阻端、电流端、挡位、量程与保险丝规格。不同型号的孔位和额定值不能照图猜。

测电压通常用高输入阻抗并接；测电流需要串入对应支路。表笔插在电流孔时跨接电源，会形成低阻通路，可能造成短路。[Fluke直流电压测量](https://www.fluke.com/en-ca/learn/blog/digital-multimeters/how-to-measure-dc-voltage-with-a-digital-multimeter)

仪表量程、额定测量类别和表笔状况也属于使用条件。本篇只安排可限流的低压直流实验，不涉及市电、充电器内部或动力电池短路测量。

开始前按“表笔孔位—功能挡—量程—接线方式—预期读数”检查一遍。测完电流后断电拆表，恢复电压孔位，避免下次误接。

## 21. 实验一：测一只电阻

**材料：**一只标称1000 Ω、额定0.25 W的电阻、万用表、记录纸。电阻不接任何电源。

步骤：

1. 电阻从其他电路中分离，确认没有外部电源。
2. 黑笔接COM，红笔接手册规定的电阻测量孔，选择合适电阻挡。
3. 表笔接触电阻两端，等读数稳定，记录量程与数值。
4. 交换表笔重复一次，比较差异；再重复接触三次。

若读到约990 Ω，不应立即判坏。应比较电阻公差、仪表误差与接触稳定性。也不要用手同时握住两个裸端来测高阻值。

蜂鸣通断挡表示读数落在仪表设定条件内；它不能证明该连接点在大电流下压降足够小。低阻测量还要考虑表笔和接触电阻。

在电路中测电阻，其他并联路径可能影响结果；元件两端有电时不能按普通电阻测量操作。[Fluke电阻测量说明](https://www.fluke.com/en/learn/blog/digital-multimeters/how-to-measure-resistance)

## 22. 实验二：用低压电源验证欧姆定律

**条件：**使用熟悉其操作、输出明确隔离且可限流的直流台式电源；输出5.0 V，限流设为适合本实验的小电流，例如20 mA。负载为上一章电阻，其他设备全部断开。

这是电源与电阻练习，不使用动力电池。若不熟悉电源设置，先由熟悉仪器的人确认输出与限流工作方式。

先断电接成：

```text
电源+ ─── 1000 Ω电阻 ─── 电源-
            │       │
            └─ 电压表 ┘
```

开启输出，测电阻两端电压，结合实测电阻计算`I_est = V/R`。例如4.98 V、998 Ω，估计电流约4.99 mA。

若要直接测电流，先关输出，按仪表手册换孔与挡位，再将仪表串入支路；确认额定值后开启输出。不得保持电流接线去跨接电源。

比较计算与直接测量结果时，考虑电源波动、仪表分流压降、分辨率与接触变化。不要求两组数字逐位相同。

完成后关输出，拆除电流接法并恢复表笔孔位。记录实际连接图和是否进入限流状态。

## 23. 实验三：分压器为什么会被负载改变

仍使用上一章电源与限流条件，取两只1000 Ω电阻串联，测中点相对负端的电压。

```text
 +5 V ── R1=1k ── A ── R2=1k ── 0 V
```

理想无额外负载时，A点约2.5 V。关闭输出，再在A到0 V之间并联第三只1000 Ω电阻，重新测量。

一般地，串联同流且`V = I R`，所以`Vout = Vin × R下 / (R上 + R下)`。有负载`RL`接入时，要先将下阻替换为`R下等效 = R2 RL / (R2 + RL)`，再计算输出，不能继续使用空载比例。

此时下半部分为500 Ω，理想输出为`5 × 500 / (1000+500) ≈ 1.667 V`。电源电流约3.333 mA，各器件功耗仍需核对。

这不是“电源变弱”的证据，而是电路结构发生了变化。用这个实验解释为什么不能用简单电阻分压给任意模块供电。

| 状态 | 上阻实测 | 下方等效电阻 | 输出预测 | 输出实测 |
|---|---:|---:|---:|---:|
| 未加第三只 | 自填 | 自填 | 自算 | 自填 |
| 加并联负载 | 自填 | 自填 | 自算 | 自填 |

## 24. 示波器与逻辑分析仪能补充什么

万用表适合观察一定时间范围内的电压、电阻和电流；示波器观察随时间变化的波形；逻辑分析仪主要按逻辑阈值采样和解码数字信号。

逻辑分析仪显示“1”，不证明电压裕度充足；万用表显示稳定5 V，也不证明没有短暂跌落。

示波器探头与逻辑分析仪有输入范围、参考连接和负载效应。常见台式示波器地夹与保护地相连，接到任意节点可能造成短路。未理解参考关系前，不把地夹接到浮动电源或动力回路。

可以先用仪器自带校准信号，在说明书允许范围内学习周期、脉宽、触发和采样。需要理解的关系是`周期T=1/f`，以及采样与带宽限制。

不同采样设置下，同一个脉冲可能被漏掉。记录“没有看到”时，还应记录观察工具有没有能力看到。

## 25. 从症状到可验证的假设

看到故障先保存原始现象，再选择下一项测量。

| 现象 | 先建立的假设 | 能区分假设的观察 |
|---|---|---|
| USB供电能开机，电池不行 | 供电支路或电压范围不符 | 两种来源在模块输入端的实测电压 |
| 舵机一动计算模块复位 | 共用电源瞬态压降 | 动作时输入波形、复位原因和支路电流 |
| 串口有乱码 | 参数或电气条件不匹配 | 确认电平后，对照双方串行配置与波形 |
| 线束一碰就断流 | 接触或应力问题 | 断电通断检查与固定方式，不带动力拉扯 |
| 相机偶尔没帧 | 供电、USB、驱动或处理阻塞 | 枚举、内核事件、帧计数与处理时间 |

一次只改变一个能解释的变量。若同时换电源、线缆、驱动和配置，恢复正常后仍不知道哪个改变有效。

故障暂时消失可以记录为“本条件下未复现”，不能直接改写为“已修复”。

## 26. 用一段程序学习功率预算

下面程序只计算，不连接任何设备。使用Python 3.10或更新版本，无第三方依赖。把代码保存为个人练习目录中的`power_budget.py`。

```python
from dataclasses import dataclass
from math import isfinite


@dataclass(frozen=True)
class Rail:
    name: str
    output_v: float
    output_a: float
    efficiency: float

    def input_power_w(self) -> float:
        values = (self.output_v, self.output_a, self.efficiency)
        if not all(isfinite(x) for x in values):
            raise ValueError("values must be finite")
        if self.output_v <= 0 or self.output_a < 0:
            raise ValueError("invalid output voltage/current")
        if not 0 < self.efficiency <= 1:
            raise ValueError("efficiency must be in (0, 1]")
        return self.output_v * self.output_a / self.efficiency


def input_current_a(rails: list[Rail], input_v: float) -> float:
    if not isfinite(input_v) or input_v <= 0:
        raise ValueError("input voltage must be positive and finite")
    return sum(rail.input_power_w() for rail in rails) / input_v


if __name__ == "__main__":
    rails = [Rail("compute", 5.0, 1.0, 0.90),
             Rail("mechanism", 6.0, 0.6, 0.85)]
    print(f"input current at 14.8 V: {input_current_a(rails, 14.8):.3f} A")
    print(f"input current at 12.0 V: {input_current_a(rails, 12.0):.3f} A")
    cable_r_ohm, cable_i_a = 0.08, 2.0
    print(f"cable drop: {cable_i_a * cable_r_ohm:.3f} V")
    print(f"cable heat: {cable_i_a ** 2 * cable_r_ohm:.3f} W")
```

运行`python3 power_budget.py`，第一项应约0.662 A，第二项约0.816 A。模型假设负载功率与效率保持不变，所以输入电压下降时输入电流上升。

真实稳压器效率随工况变化，实际机构也不是恒定负载。把程序中的常数替换为测量区间，再分别算正常与峰值工况，不把一次静态计算当成供电验收。

这张预算没有电机支路；加总前应检查是否遗漏、重复计入，或混合了不同电压域的电流。

### 自测题与参考答案

**1. 电源额定3 A，负载需要0.2 A，是否一定会被烧？**

不会仅因额定电流较大就被强灌3 A；还必须核对电压、极性、瞬态与负载是否正常。

**2. 空载测到5.0 V，可以证明给舵机供电没问题吗？**

不可以。缺少带载压降、动作峰值、动态响应和实际允许电压范围。

**3. 线缆电阻0.1 Ω，5 A时损耗多少？**

压降0.5 V，热损耗2.5 W；还应明确这个电阻是否包括来回路径及连接器。

**4. 14.8 V、2 Ah与7.4 V、4 Ah能量是否相同？**

按标称值乘积均为29.6 Wh，但实际可用能量和负载适配仍不同。

**5. 示波器地夹是不是任意接在“想当零点”的位置？**

不是。须先确定仪器参考、保护地与被测电路的关系，避免地夹引入短路。

**6. 直径更大的螺旋桨是否只影响升力？**

不是。还会改变扭矩需求、电流、转动惯量、振动和控制响应。

**7. 断电通断正常是否证明接头可承受工作电流？**

不能。还需接触电阻、热、机械固定与带载压降证据。

**8. 两个5 V稳压器能直接并联分担电流吗？**

不能默认如此。需要支持并联或经过设计的均流、隔离/冗余方案。

**9. 上位机收到命令成功响应，机构却没动作，矛盾吗？**

不矛盾。协议处理、输出波形、供电、运动与载荷结果是不同层的证据。

**10. 电池鼓包后，是否可以扎孔放气继续用？**

不可以。停止充放电与使用，按电池制造商要求隔离处理并交适当回收渠道，不做穿刺或短路实验。

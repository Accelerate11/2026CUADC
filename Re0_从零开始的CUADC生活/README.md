# 从零开始的 CUADC 学习教程

从基础概念、独立例题和分阶段练习入手，学习无人机的软件、感知、任务逻辑与调试方法。各篇可直接阅读，代码和记录表在原文中给出。

| 建议顺序 | 原有教程 | 学习重点 |
|---|---|---|
| 1 | [从零开始的 ROS 生活](Re0_从零开始的ROS生活.md) | 节点、话题、服务、参数、时间与启动 |
| 2 | [从零开始的飞控调试](Re0_从零开始的飞控调试.md) | 硬件接口、控制回路、定位、通信与阶段验收 |
| 3 | [从零开始的回看 log](Re0_从零开始的回看log.md) | 日志字段、目标与实际、故障时间线 |
| 4 | [从零开始的视觉生活](Re0_从零开始的视觉生活.md) | 图像、深度、坐标变换、时刻对齐与目标确认 |
| 5 | [从零开始的状态机生活](Re0_从零开始的状态机生活.md) | 状态迁移、异步动作、证据判定与异常处理 |

文中的设备型号和数字是注明条件的教学例子。阅读时先理解单位、坐标、时间与适用条件，再在自己的练习环境中验证。

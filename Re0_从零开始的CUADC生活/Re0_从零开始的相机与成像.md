# Re0：从零开始的相机与成像

> 学习目标：解释图像如何形成，知道像素和深度各代表什么，能独立完成相机成像、标定和测量实验。
>
> 建议先学：单位换算、三角函数、二维坐标、向量的基本含义。不需要先掌握目标检测或机器人中间件。
>
> 本篇使用通用相机和独立算例。图像检测、模型训练、目标确认及任务接口放在《从零开始的视觉生活》中学习。

## 1. 先确定我们希望相机回答什么问题

“能看到”与“能测量”之间有一段距离。
一张看起来清楚的照片，可能经过裁切、缩放和自动增强。
它适合观察，却未必适合直接套用原始相机参数。

学习时先区分三种问题：

| 问题 | 需要的信息 | 仅有一张普通彩色图像是否足够 |
|---|---|---|
| 画面里有没有某个物体 | 图像内容及判别方法 | 有时足够 |
| 物体位于相机视野的哪个方向 | 像素位置、内参、畸变模型 | 通常还需相机参数 |
| 物体离相机多远 | 深度、已知尺度或多视图几何 | 一般不能唯一确定 |

本篇按四个阶段推进：成像与参数、几何与标定、深度与时间、材料与安装。
每个阶段都要留下原始照片、设置和测量记录。
不要只保存一张“效果最好”的截图，因为它不能解释失败发生在哪里。

基本器材是能固定放置的相机、卷尺、印有文字的纸、平整墙面和均匀光源。
深度实验另需深度相机；没有时可以先完成几何计算和实验方案。
所有台架实验都可以在静止桌面上完成，不需要飞行器参与。

## 2. 从光到数字，中间发生了什么

相机记录的是经过光学系统到达传感器的光。
一个物体看起来明亮，既受表面反射影响，也受照明、观察方向和曝光设置影响。
因此，同一块白纸在阴影中可能比受强光照射的灰纸更暗。

可以把成像链条先画成：

```text
光源 → 物体反射/透射 → 镜头 → 传感器积累电荷
     → 模数转换 → 图像处理 → 编码/传输 → 程序收到图像
```

传感器在一段时间内收集光信号，这段时间就是曝光时间。
随后，模拟信号被转成数字。
彩色相机还可能进行去马赛克、白平衡、降噪、色彩变换和锐化。
程序读取到的 RGB 数字通常已经不是简单的“光子计数”。

这解释了一个常见现象：自动曝光开启时，遮住一部分画面，剩余区域也会变亮。
相机改变了整幅图像的拍摄设置，物体本身并没有改变。

学习测量时，先让照明稳定，再逐项固定自动设置。
不能控制的自动功能也要记录，例如手机的人像虚化、电子防抖或高动态范围合成。
这些功能可能改变图像几何或使一帧包含多个曝光时刻。

## 3. 像素、通道、RGB 和 BGR

图像可以看成一个二维网格。
本文用 `u` 表示横向像素坐标，用 `v` 表示纵向像素坐标。
常见约定是左上角为原点，向右 `u` 增大，向下 `v` 增大。
程序数组通常先写行再写列，因此访问方式是 `image[v, u]`。

对于宽 640、高 480 的图像，整数索引满足：

```text
0 ≤ u ≤ 639
0 ≤ v ≤ 479
数组形状通常写作 (480, 640, 通道数)
```

8 位单通道像素的数值范围是 0～255。
8 位三通道图像每个像素有三个这样的数值，不是总共只有 8 位。
RGB 顺序是红、绿、蓝，BGR 顺序是蓝、绿、红。
同一个红色像素可写成 RGB 的 `(255, 0, 0)`，或 BGR 的 `(0, 0, 255)`。

OpenCV 的常用彩色读图接口默认返回 BGR。
向要求 RGB 的接口传图前，应按接口约定转换通道顺序。
具体读图行为见 [OpenCV 官方读图说明](https://opencv.org/read-display-and-write-an-image-using-opencv/)。

深度图虽然也像一张灰度图，却不一定表示亮度。
一个 16 位像素可能存储距离编码；显示成红色或蓝色只是便于观察的伪彩色。
不能从伪彩截图的颜色反推出原始精确深度。

## 4. 传感器大小、像元大小和分辨率

传感器的有效感光区域有实际尺寸，单位通常是毫米。
像元是传感器上的感光单元，其间距常用微米表示。
输出图像分辨率则是数字图像横纵方向的采样数量。

对于没有裁切、合并像元或重采样的简化情况：

```text
传感器宽度 ≈ 横向像元数 × 横向像元间距
1920 × 3 μm = 5760 μm = 5.76 mm
```

这里说的是传感器有效区域，不是相机外壳宽度。
“1/某英寸”这类光学规格也不能直接当作传感器对角线的精确英寸值。
需要毫米尺寸时应读取器件数据表。

同样输出 1920×1080 的两台相机，传感器和像元大小可能不同。
像元更大是否一定更好，还要比较曝光、镜头、读出噪声、工艺和任务要求。
只比较像素数量，不能保证暗光、动态范围和细节表现。

还要区分“图像有多少像素”与“能分辨多细的物体”。
镜头失焦、运动模糊或强降噪会让相邻像素携带几乎相同的信息。
把模糊的 640×480 图像放大到 1920×1440，不会恢复原来没有记录的细节。

有关有效传感器尺寸、像元与物方分辨率的定义，可查阅 [Edmund Optics 成像基础](https://www.edmundoptics.com/knowledge-center/application-notes/imaging/6-fundamental-parameters-of-an-imaging-system/)。

## 5. 焦距和视场：看得宽还是看得细

焦距描述镜头的光学性质，常以毫米给出。
对于同一传感器和相近对焦条件，焦距较短通常看得更宽，焦距较长通常看得更窄。
“24 mm 等效焦距”是对照参考画幅的描述，不能直接代替真实焦距代入传感器公式。

在理想针孔、无畸变、主点居中、完整对称视场的近似下：

$$
\theta_x = 2\arctan\left(\frac{S_x}{2f}\right),\qquad
W = 2Z\tan\left(\frac{\theta_x}{2}\right)
$$

`S_x` 是有效传感器宽度，`f` 是真实焦距，两者单位一致。
`θ_x` 是水平角视场，`Z` 是沿光轴到平面的距离，`W` 是该平面上的可见宽度。
目标平面需要与光轴近似垂直。
近距离对焦、明显畸变或非居中裁切时，这些公式只能粗估。

例如 `S_x=6.4 mm`、`f=4.0 mm`，得到水平角视场约 `77.32°`。
在 `Z=2.0 m` 的平面上，可见宽度约为 `3.2 m`。
若图像宽 1280 像素，平面中心附近的平均尺度约为 `2.5 mm/像素`。
这里的平均尺度有明确距离和平面条件，不能沿用到另一距离或倾斜平面。

光轴是用于描述相机朝向的参考轴。
不要把镜头外壳最前端到物体的卷尺读数，直接当成高精度光心距离。
光学公式与视场关系可参阅 [Basler 官方焦距说明](https://docs.baslerweb.com/scan-3d-focal-length)。

## 6. 阶段实验 A：自己测一次视场

目的：把“广角”变成可测量的尺寸，并检验距离增加时视场如何变化。

步骤：

1. 固定相机，关闭会自动裁切的电子防抖和数字变焦；无法关闭时记录状态。
2. 在平整墙面横向贴一条卷尺或间距已知的纸标记。
3. 调整相机，使光轴尽量垂直墙面，卷尺尽量通过画面水平中心。
4. 记录分辨率、对焦状态、相机到墙面的距离及测量参考点。
5. 在两个不同距离各拍三张，读出画面左、右边界对应的墙面位置。
6. 计算可见宽度，并比较两个距离下 `W/Z` 是否近似不变。
7. 把卷尺移到图像上部再拍一次，观察结果是否受姿态或畸变影响。

记录表：

| 距离参考点 | 距离/m | 分辨率 | 左边界/cm | 右边界/cm | 可见宽度/m | W/Z |
|---|---:|---|---:|---:|---:|---:|
| 自填 | | | | | | |
| 自填 | | | | | | |

验收：能够报告测量条件、三次重复的范围，以及公式与实测差异的可能来源。
不要求所有镜头都得到与理想模型完全相同的结果。

故意制造一个错误：保持距离不变，开启数字变焦再测。
如果视场变窄，说明图像输出模式也参与决定最终可见范围。
常见错误是只测一次、量到相机支架、卷尺不在同一平面，以及把斜距当作 `Z`。

## 7. 曝光、增益和白平衡分别在改变什么

曝光时间越长，通常积累的光信号越多，但运动期间的图像也更容易拖长。
增益会放大已有信号，也会把已有噪声一起放大。
数字增亮无法恢复已经被噪声淹没或因饱和而丢失的细节。

可以用一个有限水杯的类比理解饱和：杯子满了以后，再加水不会记录更多水量。
高光区域变成大片相同的最大数值时，纹理可能已经丢失。
随后降低显示亮度，也不能恢复那些没有被区分记录的信号。

自动曝光会根据一定区域的图像统计调整设置。
镜头朝向亮窗时，室内目标可能变暗；遮住亮窗后，目标又可能变亮。
因此，比较两种算法或两种材料时，要避免把曝光变化误当成算法或材料差异。

白平衡调整不同颜色通道的相对增益，使某些参考颜色看起来接近预期。
自动白平衡变化可能让同一块红纸在不同帧中出现不同通道值。
做颜色实验时，应尽量固定光源、曝光、增益和白平衡。

参数名和单位由设备接口决定。
界面中的 `100` 可能表示微秒、毫秒、档位或相对数值，先读手册再换算。
[Basler 曝光时间文档](https://docs.baslerweb.com/exposure-time)展示了以微秒报告曝光、以及设置值与有效曝光可能存在差别的具体情况。

## 8. 帧率、曝光与运动模糊不是同一个量

帧率表示每秒产生多少帧。
30 FPS 对应相邻帧名义间隔约 `33.3 ms`，但每帧可以只曝光 `2 ms`。
高帧率不自动保证短曝光，短曝光也不自动保证高帧率。
实际限制还包括读出、输出格式、传输和处理。

若图像中的特征以近似恒定速度 `s` 移动，单位为像素/秒：

$$b \approx s\,t_e$$

`b` 是曝光期间拖影长度，`t_e` 是以秒表示的曝光时间。
例如 `s=800 像素/秒`、`t_e=5 ms`，预计拖影约 `4 像素`。
若允许拖影至多 `1 像素`，应把曝光控制在约 `1.25 ms` 以内。
这仍需要足够照明，否则会用更高噪声换取更短拖影。

对于近似横向平移、深度变化不大且忽略转动的情况：

$$s \approx \frac{f_x V_x}{Z}$$

`f_x` 单位为像素，`V_x` 为相对横向速度，`Z` 为光轴深度。
目标更近或焦距更大，同样平移速度通常造成更快的图像运动。
转动造成的图像运动需要另外考虑，不能只套平移模型。

帧间跳动和单帧拖影也要分开观察。
相邻两张都很清楚但位置变化很大，可能是采样间隔较长；一张图内部边缘拖长则可能是曝光模糊。

## 9. 全局快门和滚动快门

全局快门相机通常让整幅图像各像元在近似相同的时间窗口曝光。
滚动快门则按行依次开始和结束曝光，各行对应的时间窗口有偏移。
曝光时间可以都很短，但上方和下方仍可能记录不同姿态。

想象相机横向快速移动，一根真实竖直杆在逐行采集期间不断改变像素位置。
合成后的图像中，杆就可能倾斜或弯曲。
这与单行曝光期间产生的拖影是两种现象。

| 现象 | 主要时间量 | 缩短单行曝光是否一定消除 |
|---|---|---|
| 运动拖影 | 曝光时间 | 通常能减轻 |
| 滚动快门形变 | 行间时间与整帧扫描时间 | 不能保证 |

全局快门也会运动模糊，不能把“全局”理解成“任何运动都清晰”。
滚动快门在静止场景中也可能工作良好，选择要根据运动和测量要求。
电子防抖补偿后的画面可能看着稳定，却仍不能直接视为同一时刻的理想针孔图像。

在桌面实验中，缓慢左右摆动相机拍摄门框，再对比静止图像即可观察差异。
不要用手靠近旋转桨叶或高速机构来制造测试场景。
快门原理与读出时间可查看 [Basler 电子快门说明](https://docs.baslerweb.com/electronic-shutter-types)。

## 10. 对焦、景深与光圈

对焦是在给定拍摄条件下，让某一距离附近的物体在传感器上形成较清晰的像。
前后偏离这个距离时，理想点可能扩散成一个小斑。
“看起来仍然足够清晰”的距离范围称为景深。
是否足够清晰取决于你要读取的细节，不能只凭缩小预览判断。

把小字、粗线和大色块放在同一画面里，失焦往往先损害小字。
大色块仍能被看见，并不意味着角点定位和尺寸测量仍然可靠。
观察标定图像时，应放大检查角点边缘。

光圈的 f 数常写成 `N=f/D`，`D` 为有效入瞳直径。
在其他条件相近时，f 数较大意味着光圈较小，进光量减少，景深通常增加。
光圈过小还可能因衍射损害细节，所以不能无限缩小来获得清晰图像。

许多小型相机没有可调光圈，或镜头已经固定焦点。
这时可以改变照明、距离和曝光，但不应强行旋拧不支持调焦的镜头。
自动对焦还可能改变有效内参，做几何实验时应固定焦点或记录对焦状态。

景深的定义和与成像分辨率的关系，可参阅 [Edmund Optics 成像基础](https://www.edmundoptics.com/knowledge-center/application-notes/imaging/6-fundamental-parameters-of-an-imaging-system/)。

## 11. 阶段实验 B：把三类“不清楚”分开

目的：区分失焦、曝光拖影和噪声，并学习单变量比较。

步骤：

1. 固定相机，放置一张含小字、黑白边缘和大色块的纸，拍摄静止参考图。
2. 锁定对焦和白平衡，使用相机支持的手动曝光功能。
3. 保持光照和增益不变，选择三档曝光，拍静止纸并记录亮度及高光饱和。
4. 让纸沿画面水平方向缓慢移动，重复三档曝光，每档至少保留五帧。
5. 固定短曝光，逐步提高增益，观察暗部随机波动与细小文字。
6. 静止拍摄，改变纸到相机的距离，寻找失焦范围；支持手动调焦时再对比调整前后。
7. 对所有图像使用相同显示倍率，区分“暗”“噪声多”“边缘拖长”“整体失焦”。

记录表：

| 场景 | 曝光/ms | 增益及单位 | 焦点设置 | 是否移动 | 拖影/像素 | 暗部现象 |
|---|---:|---|---|---|---:|---|
| 静止参考 | | | | 否 | | |
| 移动纸张 | | | | 是 | | |
| 提高增益 | | | | 否 | | |

验收：至少指出一对仅改变一个参数的样本，并说明画质变化与原因。
“短曝光加高增益”同时改变两项，不能用于单独证明增益的影响。
如果相机不能锁定曝光，就记录实际每帧曝光，并把实验结论限定在可观察范围内。

常见错误是拿不同显示亮度、不同拍摄距离的图像做直接比较。
另一错误是只凭预览流畅，就认定每一帧都适合精确测量。

## 12. 针孔模型：从空间点算到像素

在本文的相机坐标系中，`X` 向右、`Y` 向下、`Z` 向前。
这是常见光学坐标约定，使用其他设备时仍需核对。
对于理想无畸变图像、`Z>0` 的点：

$$u=f_x\frac{X}{Z}+c_x,\qquad v=f_y\frac{Y}{Z}+c_y$$

`f_x,f_y` 是以像素为单位的有效焦距，`c_x,c_y` 是主点。
主点通常接近图像中心，但不能直接假定等于宽高的一半。
相机内参矩阵通常写成：

$$K=\begin{bmatrix}f_x&0&c_x\\0&f_y&c_y\\0&0&1\end{bmatrix}$$

这里把像素轴斜切项取为零，这是常用模型条件，不代表所有成像系统都必须如此。
焦距从毫米变成像素，需要结合有效像元间距或使用标定结果。
不能把 `4 mm` 直接填进需要像素单位的 `f_x`。

取 `f_x=f_y=600 像素`、`c_x=320`、`c_y=240`。
空间点 `(0.2, -0.1, 2.0) m` 投影到 `(380, 210)`。
另一个点 `(0.4, -0.2, 4.0) m` 也投影到同一像素。
因此，一个像素在没有深度时对应一条射线，而不是唯一空间点。

内参和投影模型的接口约定见 [OpenCV 相机模型文档](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html)。

## 13. 畸变：直线为什么会弯

针孔模型没有完整描述真实镜头。
径向畸变让像点偏离理想位置，其大小随离主点的距离变化。
切向畸变等项用于描述其他偏差；不同镜头和算法会选择不同模型。

先将理想像素变成归一化坐标：

$$x=(u-c_x)/f_x,\qquad y=(v-c_y)/f_y,\qquad r^2=x^2+y^2$$

一种常见径向模型使用：

$$x_d=x(1+k_1r^2+k_2r^4+k_3r^6)$$

`y_d` 有相同的径向倍率，实际常用模型还会加切向项。
这只是解释模型结构；实际去畸变应使用与标定模型匹配的函数。
不要手抄半套公式后省略已有参数，尤其不要混用普通模型和鱼眼模型。

拍摄门框、棋盘或方格纸，能直观看到边缘附近的直线弯曲。
去畸变可能引入黑边、裁切和新的像素采样。
得到新图像后，要使用对应的新内参，不能只换图像而沿用错误的主点。

“去畸变后的图像更自然”不是精度检验。
还应比较角点残差和已知尺寸测量，尤其观察图像边缘。
模型与去畸变流程可查阅 [OpenCV 标定教程](https://docs.opencv.org/4.x/dc/dbb/tutorial_py_calibration.html)。

## 14. 改分辨率、裁切与缩放会改变内参

假设一幅已知内参的图像先从左侧裁掉 `a` 像素、顶部裁掉 `b` 像素，
再按横纵比例 `s_x,s_y` 缩放。
在连续像素坐标、几何缩放约定下：

$$
f'_x=s_xf_x,\quad f'_y=s_yf_y,\quad
c'_x=s_x(c_x-a),\quad c'_y=s_y(c_y-b)
$$

例如 `640×480`、`f_x=600`、`c_x=320`，从左裁掉 80，再缩放为原来的二分之一。
则 `f'_x=300`、`c'_x=120`。
只把焦距减半而保持主点不变，会使反投影方向错误。

具体图像库可能按像素中心采用半像素偏移约定。
精密测量应使用实际重映射的像素变换和对应相机矩阵，不把以上简式当作所有库的逐像素定义。
此外，切换相机硬件模式可能改变读出区域、合并方式或内置处理。
只有确认新模式就是所假设的裁切和缩放，才能据此换算。

推荐把下列内容作为一组保存：

```text
相机序列号、镜头/焦点状态、宽高、像素格式、内参、畸变模型和系数
原图/去畸变图状态、裁切区域、缩放方式、标定日期
```

内参文件与图像模式要一起使用。
“这两台相机是同一个型号”不能替代对具体设备和模式的核对。

## 15. 单目标定：先把标定板拍好

标定使用已知几何结构与图像上的对应点，估计内参、畸变和各张板的姿态。
它不是在一个界面上点一下就自动得到可信结果。
拍摄质量和几何覆盖往往比多保存几十张相似照片更重要。

以棋盘格为例，先区分“方格数”和“内角点数”。
10 列、7 行方格对应 9 列、6 行内角点。
输入 `(9, 6)` 时，不能误填成 `(10, 7)`。
方格边长是相邻角点在平面上的真实间距。

采集步骤：

1. 将棋盘平整固定在不易弯曲的底板上，测量多个方格累计长度再求平均边长。
2. 固定分辨率、焦点和镜头状态，先拍静止清晰图检查所有角点。
3. 采集约 20～30 张训练图作为教学起点，覆盖中心、四角和不同画面占比。
4. 适当改变板的俯仰、偏航与距离，避免所有图都正对镜头且大小相同。
5. 每次移动后让板静止再拍，避免滚动快门形变和拖影。
6. 另拍一组位置与角度不同的检查图，不参与内参拟合。
7. 保存原始分辨率图像，标注方格边长、设备和模式。

极端斜视导致角点挤在一起，和所有图都正对镜头一样，都不利于可靠估计。
不要在采集期间变焦、自动调焦或启用动态裁切。
打印机缩放和纸张弯曲会让“已知几何结构”失真，算法无法自动消除这些输入错误。

## 16. 可选 OpenCV 实验：用真实照片计算标定

本实验需要 Python 3、`opencv-python`、`numpy`，以及上一章实际拍摄的棋盘图。
以下程序不包含照片，也不会生成虚构标定结果。
没有满足输入条件的照片时，先完成采集，不要把任意网络图片当作同一台相机的数据。

把训练照片放入 `train_images`，独立检查照片放入 `check_images`。
两组均可使用 PNG 或 JPEG；图像尺寸必须一致，棋盘内角点必须完整可见。
将下面程序保存为自己的实验脚本 `calibrate.py`。

```bash
python -m pip install opencv-python numpy
python calibrate.py train_images check_images --cols 9 --rows 6 --square-m 0.025
```

`0.025` 表示本例假设方格边长 25 mm，实际实验必须换成实测值。
程序使用普通针孔加五参数畸变模型，不适用于所有鱼眼相机。

```python
import argparse
import json
from pathlib import Path
import cv2 as cv
import numpy as np

parser = argparse.ArgumentParser()
parser.add_argument("train_dir", type=Path)
parser.add_argument("check_dir", type=Path)
parser.add_argument("--cols", type=int, required=True)
parser.add_argument("--rows", type=int, required=True)
parser.add_argument("--square-m", type=float, required=True)
args = parser.parse_args()
if min(args.cols, args.rows) < 3 or args.square_m <= 0:
    raise ValueError("角点行列数应至少为 3，边长应大于 0")
if args.train_dir.resolve() == args.check_dir.resolve():
    raise ValueError("训练和检查应使用不同目录、不同采集照片")
pattern = (args.cols, args.rows)
board = np.zeros((args.cols * args.rows, 3), np.float32)
board[:, :2] = np.mgrid[0:args.cols, 0:args.rows].T.reshape(-1, 2)
board *= args.square_m
criteria = (cv.TERM_CRITERIA_EPS + cv.TERM_CRITERIA_MAX_ITER, 40, 0.001)
image_size = None

def load_views(folder):
    global image_size
    if not folder.is_dir():
        raise ValueError(f"输入目录不存在: {folder}")
    views = []
    for path in sorted(folder.iterdir()):
        if path.suffix.lower() not in {".png", ".jpg", ".jpeg"}:
            continue
        gray = cv.imread(str(path), cv.IMREAD_GRAYSCALE)
        if gray is None:
            raise ValueError(f"无法读取: {path}")
        size = (gray.shape[1], gray.shape[0])
        if image_size is None:
            image_size = size
        if size != image_size:
            raise ValueError(f"图像尺寸不一致: {path}")
        ok, corners = cv.findChessboardCorners(gray, pattern)
        if not ok:
            print("未使用，角点检测失败:", path.name)
            continue
        corners = cv.cornerSubPix(gray, corners, (11, 11), (-1, -1), criteria)
        views.append((path.name, corners))
    return views

train = load_views(args.train_dir)
check = load_views(args.check_dir)
if len(train) < 12 or len(check) < 4:
    raise ValueError("教学实验至少需要 12 张有效训练图和 4 张独立检查图")
rms, K, distortion, rvecs, tvecs = cv.calibrateCamera(
    [board.copy() for _ in train], [p for _, p in train], image_size, None, None
)

def point_rms(corners, rvec, tvec):
    projected, _ = cv.projectPoints(board, rvec, tvec, K, distortion)
    residual = corners.reshape(-1, 2) - projected.reshape(-1, 2)
    return float(np.sqrt(np.mean(np.sum(residual * residual, axis=1))))

print("训练整体 RMS/像素:", float(rms))
for (name, corners), rvec, tvec in zip(train, rvecs, tvecs):
    print("训练单图 RMS:", name, point_rms(corners, rvec, tvec))
for name, corners in check:
    ok, rvec, tvec = cv.solvePnP(board, corners, K, distortion)
    if not ok:
        raise RuntimeError(f"检查图姿态求解失败: {name}")
    print("检查单图 RMS:", name, point_rms(corners, rvec, tvec))
result = {
    "image_size": list(image_size), "model": "opencv_pinhole_5",
    "K": K.tolist(), "distortion": distortion.reshape(-1).tolist(),
    "square_m": args.square_m, "train_rms_px": float(rms),
    "train_files": [name for name, _ in train],
    "check_files": [name for name, _ in check],
}
Path("calibration_result.json").write_text(
    json.dumps(result, ensure_ascii=False, indent=2), encoding="utf-8"
)
```

这里“检查图独立”指不参与内参和畸变拟合，检查图姿态仍由其角点估计。
姿态拟合会吸收一部分误差，因此还需要下一章的物理测量检查。
角点函数和标定接口见 [OpenCV 官方标定 API](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html)。

## 17. 阶段实验 C：怎样判断标定是否可信

重投影是把已知板上的空间点，用估计参数重新投到图像。
预测像素与实测角点之间的差叫重投影残差。
本篇程序使用的单图 RMS 是每个点二维距离平方的平均值再开方，单位为像素。

$$E=\sqrt{\frac{1}{N}\sum_{i=1}^N[(u_i-\hat u_i)^2+(v_i-\hat v_i)^2]}$$

残差小表示模型更贴合这些观测，不等于所有距离上的毫米误差都小。
例如方格边长整体填错，会改变平移的尺度，重投影仍可能很好。
只用画面中央很小的棋盘拟合，也不能充分检验边缘畸变。

步骤：

1. 查看每张训练图残差，回到原图检查高残差样本的模糊、弯板和错角点。
2. 查看独立检查图，并比较中心与边缘、近处与远处的结果。
3. 用固定 `K` 和畸变重做另一组独立采集，检查参数是否明显漂移。
4. 另放一块已知尺寸的平面，结合其姿态或已知距离进行尺寸测量。
5. 用卷尺测量结果做独立对照，写明卷尺和距离参考点的不确定性。
6. 若更换焦点、镜头或图像模式，重新验证；不能直接沿用旧结论。

| 数据组 | 有效图数 | RMS 中位数/像素 | 最大值/像素 | 边缘覆盖 | 已知长度误差 |
|---|---:|---:|---:|---|---|
| 训练组 | | | | | |
| 独立检查组 | | | | | |

验收：能解释高残差来自哪张图、什么区域，以及独立尺寸检查是否满足事先约定的用途。
不设所有设备通用的“低于某个像素就合格”门槛。
允许的尺寸误差应由测量任务决定，再据此决定是否需要改进采集或模型。

## 18. 外参：相机与其他参考点的位置关系

内参描述相机内部的投影关系，外参描述两个坐标系之间的刚体变换。
用 `p_A=R_AB p_B+t_AB` 表示把 B 系坐标转换到 A 系。
`t_AB` 是 B 系原点在 A 系中的位置，用 A 系分量表达。
不能只写一个没有方向说明的“相机外参”。

如果相机坐标系 C 与支架坐标系 M 朝向相同，
相机原点在 M 系的位置为 `(0.05, 0.02, 0.10) m`，则：

```text
p_M = p_C + (0.05, 0.02, 0.10)
相机中的点 (0, 0, 2) m → 支架中的点 (0.05, 0.02, 2.10) m
```

有旋转时，需要先旋转点的坐标，再按定义加平移。
逆变换为 `p_B=R_AB^T(p_A-t_AB)`，平移不能简单原样复制。

真实相机的参考点可能是光心、某个成像器坐标原点或厂商定义的深度起点。
外壳螺孔和镜头保护玻璃并不自动等于这些原点。
高精度测量应查机械图和 SDK 坐标定义，而不是只拿尺子量外壳。

另外，OpenCV 标定返回的每张 `rvec/tvec` 是板坐标到相机坐标的姿态。
它不是相机到支架的固定安装外参。
与其他传感器的外参需要相应测量或联合标定。

## 19. 双目为什么能测深度

两只眼睛从不同位置看同一个点，会得到不同的图像位置。
双目相机利用已知基线与对应像素，求交会几何。
对经过校正、平行等效相机、共用焦距并已处理主点偏移的简化情况：

$$Z=\frac{f_xB}{d}$$

`B` 是基线，`d` 是水平视差，`f_x` 和 `d` 都用像素单位。
`B=0.05 m`、`f_x=600 像素`、`d=15 像素`，得到 `Z=2.0 m`。
同一配置下 `d=7.5 像素`，深度为 `4.0 m`。

视差越小，同样大小的视差误差造成的深度误差越大。
一阶近似为：

$$|\Delta Z|\approx\frac{Z^2}{f_xB}|\Delta d|$$

在上例中，`|Δd|=0.2 像素` 时，2 m 处约对应 `2.7 cm`，4 m 处约对应 `10.7 cm`。
这是局部误差传播，不包含错误匹配、标定偏差或遮挡。
错误匹配可能产生离谱的深度，不能用这个小误差公式解释。

重复纹理和纯色墙都可能使左右对应关系不明确。
前景边界还会出现一只相机能看到、另一只相机看不到的区域。
因此，“画面里有这个像素”不保证该像素有可信深度。

## 20. 被动双目、主动双目、结构光与 ToF

这些技术都可能输出深度图，但测量原理和失败条件不同。
不能看到相机带红外投射器，就认定它们使用同一种深度方法。

| 方法 | 深度主要来自什么 | 主动光的作用 | 常见困难 |
|---|---|---|---|
| 被动双目 | 两个相机图像的对应关系 | 可以没有 | 暗光、低纹理、重复纹理 |
| 主动双目 | 双目对应关系 | 给场景补充可匹配纹理 | 投射纹理被淹没、反光、遮挡 |
| 结构光 | 投影图案与观测图案的几何关系 | 形成已知编码或图案 | 强背景光、透明反光、图案干扰 |
| ToF | 发射光与返回光之间的传播信息 | 提供测距信号 | 多路径、背景光、反射率、测距模糊 |

主动双目通常仍是在两张实际图像间寻找匹配。
结构光通常利用已知投影关系解算几何，具体编码与实现依设备而异。
两类系统都可能使用散斑，看到散斑本身不能判断内部算法。

ToF 也不只有一种实现。
直接 ToF 测量脉冲传播时间；间接 ToF 可根据调制信号的相位差估计距离。
最简单往返时间模型为 `r=cΔt/2`，分母 2 来自光走了往返两段路。
真实设备还需处理噪声、标定、频率选择和多路径。
原理综述可参阅 [ToF 技术研究论文](https://arxiv.org/abs/2012.06772)。

选型时应先列出距离、光照、材料、运动与允许误差，再比较器件实测。
技术名称不能直接代替某台设备在某个场景下的精度保证。

## 21. 深度单位、光轴深度与斜距

深度图中的数值必须结合编码与单位读取。
若原始整数为 `q`、深度比例为 `s m/单位`，则 `Z=q×s`。
`q=2000` 在 `s=0.001` 时表示 2 m，在 `s=0.0001` 时则表示 0.2 m。
不能凭整数位数猜单位，也不能假设所有设备的比例永远不变。

对于已经去畸变或由匹配投影模型处理的像素：

$$X=(u-c_x)Z/f_x,\quad Y=(v-c_y)Z/f_y,\quad r=\sqrt{X^2+Y^2+Z^2}$$

`Z` 是沿相机光轴的深度，`r` 是到坐标原点的欧氏距离。
离图像中心越远，两者可能差得越明显。
某些设备原始测量与 SDK 输出经过不同几何处理，应以输出接口定义为准。
RealSense 的深度比例、坐标和反投影定义见 [官方投影文档](https://dev.realsenseai.com/docs/projection-in-realsense-sdk-2-0/)。

以下是只依赖 Python 标准库的独立算例，不读取设备：

```python
from math import atan, degrees, sqrt

sensor_mm, focal_mm, z_m = 6.4, 4.0, 2.0
fov_deg = degrees(2 * atan(sensor_mm / (2 * focal_mm)))
width_m = z_m * sensor_mm / focal_mm
print(f"水平视场: {fov_deg:.2f} 度; 平面宽度: {width_m:.3f} m")

fx = fy = 600.0
cx, cy = 320.0, 240.0
x, y, z = 0.2, -0.1, 2.0
u, v = fx * x / z + cx, fy * y / z + cy
print(f"投影像素: ({u:.1f}, {v:.1f})")

u2, v2, raw, scale = 620.0, 240.0, 2000, 0.001
z2 = raw * scale
x2, y2 = (u2 - cx) * z2 / fx, (v2 - cy) * z2 / fy
distance = sqrt(x2*x2 + y2*y2 + z2*z2)
print(f"光轴深度: {z2:.3f} m; 点: ({x2:.3f}, {y2:.3f}, {z2:.3f}) m")
print(f"斜距: {distance:.3f} m")

baseline, disparity = 0.05, 15.0
stereo_z = fx * baseline / disparity
blur = 800.0 * 0.005
print(f"双目深度: {stereo_z:.3f} m; 预计拖影: {blur:.1f} 像素")
assert abs(width_m - 3.2) < 1e-12
assert (u, v) == (380.0, 210.0)
assert abs(distance - sqrt(5.0)) < 1e-12
assert abs(stereo_z - 2.0) < 1e-12
assert abs(blur - 4.0) < 1e-12
```

应得到视场约 `77.32°`、点 `(1,0,2) m`、斜距约 `2.236 m`。
验收：改变深度比例和像素位置，提前判断结果的变化方向，再运行核对。
常见错误是把毫米与米混用、把无效零值当作紧贴镜头的真实物体。

## 22. RGB-D 配准：同一像素不一定看同一处

RGB 相机和深度相机可能有不同镜头、分辨率与安装位置。
彩色图的 `(u,v)` 与深度图的 `(u,v)` 因而未必对应同一条空间射线。
直接用彩色目标中心去索引未经配准的深度图，可能读到背景。

空间配准通常包含以下关系：

```text
深度像素 + 深度值
→ 使用深度相机内参反投影成三维点
→ 使用深度到彩色的外参转换坐标
→ 使用彩色相机内参和畸变模型投影到彩色图
```

由于遮挡、离散采样和视场差异，配准不能保证所有像素都有有效值。
在物体边界附近，一个彩色像素还可能混入前景与背景。
因此，要检查有效深度比例和局部一致性，不能一味扩大窗口取平均。

RealSense SDK 的对齐处理是上述空间关系的一种实现，接口说明见 [官方投影与图像对应文档](https://dev.realsenseai.com/docs/projection-in-realsense-sdk-2-0/)。
使用其他设备时应查它的坐标、单位和重采样定义。

空间配准不等于时间同步。
即使两幅静态图能完美重合，若曝光相差 30 ms，运动目标仍会在两图中出现在不同位置。
可用一张移动的有色纸，在静止与运动两种条件下对比边缘重合情况。
静止对齐好、运动时偏离明显，应继续检查时间而不是只调整外参。

## 23. 一帧图像到底是什么时刻的

至少要分清曝光时刻、设备生成时间、主机接收时间和程序使用时间。
它们之间可能经过读出、编码、USB 传输、驱动排队和计算。
在程序取到图像时调用当前时间，只能得到取图时刻，不能自动得到曝光时刻。

常见记录可以写成：

| 字段 | 含义 | 需要核对的内容 |
|---|---|---|
| frame_id | 帧编号 | 是否跳号、重复、回绕或重启 |
| capture_stamp | 设备报告的帧时间 | 单位、起止/中点语义、时钟域 |
| receive_stamp | 主机接收或回调时间 | 使用哪一种主机时钟 |
| use_stamp | 算法实际使用时间 | 是否已经排队、是否重复使用 |
| exposure | 曝光长度 | 是设置值还是该帧实际值 |

设备硬件时钟可能从设备上电开始计时，主机系统时钟可能表示日期时间。
两个数字都以毫秒为单位，也不代表可以直接相减。
没有时钟映射时，`主机时间-设备时间` 不能称为端到端延迟。

即使建立偏移映射，两个时钟还可能存在频率偏差，长时间运行后产生漂移。
相机重连、休眠或设备重启后，也要重新检查映射是否有效。
RealSense 提供帧元数据和时间域查询，详见 [帧元数据说明](https://dev.realsenseai.com/docs/frame-metadata/)及[多相机时间域说明](https://dev.realsenseai.com/docs/multiple-depth-cameras-configuration/)。

软件把两帧放入一个集合，也不自动保证它们具有精确相同的曝光时间。
SDK 配对、硬件触发和曝光同步是相关但不同的机制。
RealSense 对同步质量和启用硬件同步的限制说明见 [官方帧管理文档](https://dev.realsenseai.com/docs/frame-management/)。

## 24. USB 带宽、排队与采集实验

先计算未压缩数据量：

$$带宽 \approx 宽\times高\times每像素字节数\times帧率$$

`1280×720`、RGB8、30 FPS 的图像流约为 `82.94 MB/s`。
同尺寸、16 位深度、30 FPS 约为 `55.30 MB/s`。
两者合计约 `138.24 MB/s`，还没有计入传输开销、额外流及内存拷贝。
MB/s 与 Mb/s 相差 8 倍，接口标称速率也不是保证可用的应用吞吐量。

压缩会改变数据量和延迟，不能对 JPEG 直接套“每像素三字节”的传输估算。
多个插口还可能共享同一主控制器或集线器。
高带宽、供电不足、线材问题、设备发热和主机处理不足应分别排查。

阶段实验 D：

1. 只开启一条低分辨率图像流，记录至少 60 秒帧编号和主机接收时刻。
2. 在同一主机时钟域内统计相邻接收间隔，记录中位数、较大间隔及最大值。
3. 增加分辨率或第二条流，保持其他设置不变，重复记录。
4. 增加可控的算法负载，观察程序是处理旧帧、丢帧还是阻塞。
5. 关闭负载恢复基线；必要时换接口或短线，每次只改变一项。
6. 记录实际协商的 USB 速度、输出格式和设备温度信息，而不只记录插口颜色。

| 流与模式 | 目标 FPS | 收到帧数/时长 | 接收间隔中位数/ms | 最大/ms | 跳号 | CPU/备注 |
|---|---:|---|---:|---:|---:|---|
| 低负载基线 | | | | | | |
| 加第二条流 | | | | | | |
| 增加处理负载 | | | | | | |

验收：能区分接收间隔抖动、明确跳号和处理队列增长。
本实验只用主机接收时间时，不能声称测出了曝光到算法的绝对延迟。
若后续处理只需要最新帧，应研究有界队列和丢弃策略，并记录被丢弃的帧。
队列选择应与应用需要一致，离线完整记录和实时控制的取舍可能不同。

## 25. 阶段实验 E：材料、光照与固定安装

深度相机不是对所有表面都可靠的尺子。
透明材料可能让相机测到后面的物体；镜面反射可能给出无效或错误对应。
低纹理平面可能让双目难以匹配，强背景红外可能降低主动投射的作用。
这些都应通过具体设备实验验证，不能用一项室内演示概括全部环境。
测试思路可参阅 [RealSense 深度质量测试方法](https://www.realsenseai.com/wp-content/uploads/2019/11/RealSense_DepthQualityTesting.pdf)。

准备平整哑光纸、带纹理纸、深色材料、光亮表面和透明板。
透明板后放置有纹理背景，以便观察读数究竟来自哪一层。
反光与透明样品保持稳固，避免把强光或反射光束引向眼睛。

步骤：

1. 固定相机、距离和角度，在均匀室内光下测哑光参考板，基线实验让板近似垂直光轴。
2. 在同一中央区域，连续保存约 100 帧原始深度及有效值掩码。
3. 逐一替换材料，记录有效比例、有效深度中位数和帧间波动。
4. 改变表面倾角，观察无效区域和边缘是否扩大。
5. 条件允许时比较阴影、室内与日光场景，记录时间、方向和实际曝光。
6. 对透明板同时记录板和背景的真实位置，避免把稳定的背景读数当成板深度。
7. 相机预热后重复基线；检查线缆牵拉、支架松动和镜头污染。

有效比例的分母是预先选定的全部 ROI 像素。
不能先删掉无效值，再声称“剩下的有效比例是 100%”。
中位数比较稳健，但也可能稳定地指向背景；稳定不能代替正确。

本实验可对每帧 ROI 的有效像素求深度中位数，再报告这些中位数的中位数和 5%～95% 分位区间。
把后一区间宽度作为一种明确的帧间波动指标，同时单独记录完全没有有效值的帧数。
比较参考距离时，要用同一深度参考点和沿光轴的距离，不能拿斜距直接相减。
若物体倾斜或 ROI 跨越多个表面，应分区分析，不能把真实几何变化全部算成噪声。

| 材料 | 光照/角度 | 参考距离/m | 有效比例 | 深度中位数/m | 帧间波动 | 测到哪一层 |
|---|---|---:|---:|---:|---:|---|
| 哑光参考 | | | | | | |
| 带纹理纸 | | | | | | |
| 光亮表面 | | | | | | |
| 透明板 | | | | | | |

验收：至少找到一种失败条件，保存原图、原始深度与设置，并用物理原因解释。
精度、有效率和时间稳定性要分别报告，不用单一“平均距离”概括。

固定安装时，给镜头留足视野和散热空间，让线缆有应力释放。
软支架可以减小部分振动，也可能让相机相对其他传感器运动，破坏固定外参假设。
拆装、碰撞、换焦点、改分辨率或观察到几何漂移后，都应复查标定和已知尺寸测量。
记录安装照片、螺钉状态、参数文件与日期，便于判断变化从何时开始。

## 26. 自测、答案与独立结业任务

先遮住答案，写下假设、公式和单位，再计算。

**题 1：** 640×480 的 BGR8 图像，`image[100, 200]` 对应哪个像素？单帧未压缩数据量多少？

答案：`u=200,v=100`；`640×480×3=921600 字节`，约 `0.922 MB`。
不要交换行列，也不要把它写成 921600 位。

**题 2：** `f_x=800 像素`，目标横向速度 `1 m/s`，`Z=4 m`，曝光 `10 ms`，预计拖影多长？

答案：在纯横向平移等近似下，图像速度约 `200 像素/秒`，拖影约 `2 像素`。
若还存在相机转动、深度变化或明显畸变，应重新建模。

**题 3：** 帧率 60 FPS、曝光 1 ms，能否保证没有滚动快门形变？

答案：不能。帧率和曝光不足以确定各行曝光时刻，还要知道读出方式和行间偏移。
短曝光主要减轻每行曝光期间的拖影。

**题 4：** 原图 `f_x=700,c_x=320`，从左裁掉 20 像素后等比例缩小至一半，新参数是什么？

答案：按第 14 章的连续坐标约定，`f'_x=350,c'_x=150`。
实际像素中心的映射还应核对图像库约定。

**题 5：** 标定的 RMS 很低，为什么已知长度测量仍可能错误？

答案：方格尺度填错、板不平、图像模式不一致、检查只覆盖中心等都可能造成问题。
拟合残差只检验观测与模型的贴合程度，还需要独立物理量验证。

**题 6：** `f_xB=30 像素·米`，视差从 15 变成 10 像素，深度怎样变化？

答案：由 `2 m` 变成 `3 m`。视差减小，深度增大，不是线性减小。

**题 7：** 某像素反投影得到 `(1,2,2) m`，光轴深度与斜距分别是多少？

答案：`Z=2 m`，斜距 `sqrt(1²+2²+2²)=3 m`。
不能把所有深度图都解释成从镜头到表面的直线距离。

**题 8：** 彩色与深度配准后，运动物体仍出现边缘错位，先查什么？

答案：先核对两路曝光时刻、时间域、帧配对和滚动快门，再结合静态实验检查空间参数。
只改外参可能让某一种速度下看起来对齐，却破坏静态几何。

**题 9：** 主机时间 10000 ms，设备时间 2000 ms，能否认定延迟 8 秒？

答案：没有共同时间原点和时钟映射时不能；单位相同并不代表时钟域相同。

**题 10：** 透明板中央深度连续 100 帧都为 3 m，板实际位于 1 m，能否认为板测得很准？

答案：不能，可能测到了 3 m 处的背景；低波动只说明读数稳定。

独立结业任务：为一个桌面测量需求写一页实验报告。
例如，在限定光照和距离范围内，测量哑光平面上标记点的空间位置。
报告应包括以下并列内容：

- 需求：目标大小、距离范围、允许误差、帧率与运动范围。
- 设置：设备与镜头、模式、曝光、增益、焦点、内参和坐标定义。
- 数据：正常样本、失败样本、原始图像、深度单位和时间字段。
- 验证：独立参考值、重复次数、有效比例、误差与时间稳定性。
- 适用范围：已经实测的条件，以及尚未完成验证的条件。

完成标准是另一位同学能按记录复现实验，并能解释至少一种失败。
把“看到物体”推进到“知道测到了什么、何时测到、误差来自哪里”，才建立起相机测量的基础。

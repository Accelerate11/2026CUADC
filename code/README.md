# CUADC Code

本目录用于整理和记录团队历年 CUADC（中国大学生飞行器设计创新大赛）相关代码。

## 目录结构

```text
code/
├── 2025code/        # 2025 年比赛代码及历史版本
└── 2026code/        # 2026 年比赛代码
    ├── 状态机/      # 无人机自主任务状态机
    └── 视觉/        # 目标检测、定位与视觉处理
```

2025 年代码主要围绕ROS1展开，保留ROS1节点风格。
2026 年代码主要围绕ROS2展开，同时，全流程运动学控制和轨迹规划更加复杂。

仓库中的部分代码为整理后的开源版本，主要用于学习和交流。实际飞行参数、硬件配置及部分比赛相关算法需要根据具体平台重新标定和调整。

> ⚠️ 请勿未经测试直接用于真机飞行。建议先完成代码检查、仿真测试及无桨测试。

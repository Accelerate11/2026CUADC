## 构建环境说明

当前用户目录中的 setuptools 82.0.1 与 Humble 的 colcon 可编辑安装流程不兼容，首次构建报 `option --editable not recognized`。最终采用 Ubuntu 系统 setuptools 59.6.0，通过以下方式完成正常工作区脚本的编译：

```bash
PYTHONNOUSERSITE=1 CUADC_SKIP_ROSDEP_CHECK=1 bash scripts/build_onboard.sh
```

测试环境的 rosdep 数据库尚未初始化，因此本次明确跳过 rosdep 检查。实际构建已找到所需 ROS 依赖，但不据此宣称完成了机载环境的完整依赖安装。没有为此更改系统 Python 或安装新软件。

本次验证没有执行完整视觉推理，也没有进行实际相机采集、飞控串口通信、舵机动作、定位与航向锁定、自动起降或实飞。测试环境未安装原视觉依赖中的 pyrealsense2 和 Ultralytics；这些需要在机载环境准备。

模型完整性检查、源码一致性检查与软件构建结果，不能代替原飞机的硬件适配和实机测试。本次交付是经过软件验证的源码组织版本。

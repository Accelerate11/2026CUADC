# 从区域覆盖仿真到实机危险物侦察

本流程只覆盖危险物侦察。

## 1. 任务信息隔离

实机状态机只能获得竞赛规定的侦察区域边界、RTK 基站和飞机状态，不能获得桶位。

仿真中的随机桶位真值只能用于：

- 生成 Gazebo 场景。
- 任务结束后评分。
- 分析模型误差。

不能把 `recon_targets`、桶编号或类别传入飞行状态机。

## 2. 覆盖航线

状态机根据公开区域边界生成往复式航线。航带间距必须小于实机相机在侦察高度下的有效横向地面覆盖宽度，并留出图像畸变、姿态误差和 RTK 误差余量。

实机前需要标定：

- 侦察高度下相机的有效地面覆盖 X/Y。
- 相机光轴与机体 Z 的夹角。
- 图像 U/V 轴与 MAVROS 本地 ENU 的方向关系。
- 云台或机体偏航对图像投影的影响。

## 3. 发现后视觉居中

覆盖飞行中发现目标后，先利用检测框和相机内外参估算目标地面位置，再做短距离居中。只有实际进入接受半径并稳定后，才累计类别证据。

仿真使用等效地面覆盖做平面投影。实机应替换为：

~~~text
pixel + depth/ground-plane
  -> camera optical frame
  -> body frame
  -> MAVROS map ENU
~~~

如果没有可靠深度，可使用已知地面平面、飞行高度、相机内参和姿态做射线与平面求交。

## 4. RTK 基准

必须记录：

- RTK 基站 WGS84 纬度、经度和椭球高。
- 同时刻的飞机 NavSatFix。
- MAVROS 本地 ENU 位姿。
- RTK ENU 到 MAVROS ENU 的水平偏航角。

水平位置通过 WGS84 -> ECEF -> 基站 ENU -> MAVROS ENU 转换。

不要把 RTK 基站高程或 GNSS 高程直接写入 MAVROS 本地 Z。垂直控制继续使用本地里程计和相对起飞高度；只有完成 geoid/ellipsoid、天线杆高和本地原点校准后，才能融合绝对高程。

## 5. 双可视化

地面调试默认保留：

- Gazebo/实机地面站态势窗口。
- OpenCV 实时识别窗口。

窗口不属于控制闭环。关闭 OpenCV 窗口不能停止推理或飞行。无人值守部署应关闭 GUI 后做一次完整回归。

## 6. 模型数据

重点补充：

- 同一类别在顺/逆时针旋转下的样本。
- 有毒品与自燃物品的 hard negative。
- 桶内偏移、边缘视角、运动模糊和不同曝光。
- 空桶、桶壁、地面纹理和其他标识。
- 视觉居中前后的尺度变化。

验证时分别统计目标发现率、空间定位误差、类别准确率和空区域误报，不要只看最终总分。

# Notice

CUADC Hazard Recognition Simulation is a standalone ROS 2/Gazebo environment for unknown-position hazard search. It does not include or depend on the separate full-process CUADC mission package at runtime.

Original project code is distributed under LGPL-3.0-only. Modified Iris assets and CUADC hazard-marker textures are documented in `THIRD_PARTY_NOTICES.md`. The trained ONNX detector is not included.

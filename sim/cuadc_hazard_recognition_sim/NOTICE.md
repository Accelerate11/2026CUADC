# Notice

This package is a standalone hazard-marker recognition scene for CUADC simulation.

The hazard marker textures under:

```text
models/hazard_marker/materials/textures
```

were copied from the previously prepared CUADC full-flow simulation package and were generated from the CUADC competition attachment 11 hazard chemical marker PDF supplied for this project. They are intended for competition simulation and training use.

This package does not modify or depend on the full-flow `cuadc_rescue_sim` package at runtime.
